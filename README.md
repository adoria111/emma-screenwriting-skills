# 艾玛短剧 · 编剧 Skills（Beta 六技能公开版）

六个独立的短剧创作方法，覆盖读对标、做改编、设计期待、扩写集纲、诊断对白与删减冗余。可以按自己的问题选用，不要求每次跑完六个。

## 包含什么

| 标识 | 用在什么时候 | 主要产物 |
| --- | --- | --- |
| `em-structure` | 有原稿，想知道结构为什么有效或哪里不顺 | 有原文依据的结构判断 |
| `em-adaptation` | 要从对标机制设计新故事，或按指定维度改设定 | 新方案、事件链及连带影响检查 |
| `em-expectation` | 要明确观众在等什么，检查前后场兑现 | 目标、盼头、断点与兑现诊断 |
| `em-outline-to-script` | 已经确定事件与集尾，需要完整场次 | 忠实集纲的正文 |
| `em-dialogue` | 一场戏能成立，但台词重复或不够可演 | 逐项判断与修改稿 |
| `em-script-trim` | 需要减少冗余，保护信息与情绪 | 删除依据、接法与精简稿 |

每个目录内的 `SKILL.md` 是完整方法，`agents/openai.yaml` 是供支持该格式的工具使用的界面配置。六项正文均可独立读取，不依赖私人素材库或额外参考文件。

## 安装口令

把下面这段发给有 GitHub 访问和文件操作能力的 AI 编程助手：

> 帮我安装「艾玛短剧 Beta 六技能」：从 GitHub 克隆 adoria111/emma-screenwriting-skills 仓库，将 skills/ 下的 6 个技能目录安装到当前工具支持的项目级 Skills 目录；已有同名技能先备份，不要直接覆盖。装好后用中文列出六个技能的用途和触发方式，并带我用其中一个完成一次小练习。

仓库：<https://github.com/adoria111/emma-screenwriting-skills>

仓库的 `skills/` 目录就是安装来源，内含下面6个独立目录：

```text
em-structure
em-adaptation
em-expectation
em-outline-to-script
em-dialogue
em-script-trim
```

不同工具识别的项目级目录可能不同，让当前工具按自己的规则安装。不要仅把文件放进一个任意名为 `skills` 的目录，就声称已成功加载。

## 只用普通聊天，也可以用方法

不会安装时，打开想用的 `SKILL.md`，复制其中的方法正文，粘贴到聊天框，再附上这次的要求和原文。普通聊天里只输入英文技能名，不代表已经读取了方法。

每次说明四件事：材料、做什么、哪些不能改、想拿到什么。

例如使用“中文对白诊断”时，在方法后面接上：

```text
请修改下面这一场的对白。
目标：减少同一个理由、同样力度的重复争论。
范围：只改对白，保留动作、人物关系和原集尾。
必须保留：女主第一次公开反抗，以及对手对此的回应。
交付：说明关键取舍，再交完整修订场次。

【在这里粘贴自己的原文】
```

拿到回答后，再看：根据哪句原文、具体改了哪里、有没有碰到不能改的内容。安装和复制方法是两种使用途径，后续仍需要提供本次任务与素材。

## 版本来源

版本日期：2026-10-06。

结构拆解、期待设计、集纲扩写、中文对白诊断、剧本删减五项，原样选自用户已有的 2026-09-30「Alpha/Beta均衡版」中的 Beta精编专业版，包含各自的界面配置。

故事改编是本次新增的独立公开版：依据用户已安装的 `em-adaptation` 方法提炼，保留功能迁移、改动范围与连带影响检查，移除对私人参考材料的依赖。它不是原包中已有同名Beta文件的原样副本。

Beta在此表示方法版本与内容取向，不代表经过统一模型基准测试。本次检查覆盖文件结构、材料边界与配套课程，不声称已完成六项技能的跨模型实测。
