# 六组案例：有效机制、证据与不能照抄的地方

编号见 [来源索引](sources.md)。均为本地文字材料，未核原视频及市场表现。区分“正文呈现”“原作者分析”“本包推导”。用这些案例校准方法，不复用专属对白、人物与事件组合。

## C01《My Guardian Angel Fell for Me》：照料越深，代价越大

**范围**：第1—3集正文＋拆解，235行。第1集救人建立守护者关系；第2集明确“爱上人类会失去力量”的限制；第3集羽毛暴露身份破绽，照料推动双向关心，同时伤痕加重。

**可迁移**：一条规则同时制造行为选择、可见代价和关系悬念。先有“救不救”的动作，再解释必须支付的代价；亲密细节既推进关系又增加暴露风险。来源1-1/1-2、2-1、3-1；原作者分析L195—235。

**需纠偏**：3-1中“I work here.”的中文对照被错配成不能暴露魔法的内心句（L135—139）；1-2人物行只列Sarah却有Nancy出镜。不能照抄说话人、翻译和名单。后续未提供，不能宣称诅咒已解决。

## C02《The Rise of the Lycan Queen》：同一身份完成羞辱、能力与目标转换

**范围**：第1—5集正文＋分析。第1集“无狼”检测引出被弃危机；2—3集逃亡、背叛与保护；第4集养父救援后跳至成年，训练和觉醒证明能力；第5集遮息道具与寻亲目标把强能力转换为仍有约束的行动。

**可迁移**：把受轻视的原因、潜在优势和之后的风险绑定在同一身份规则上。先表现无需觉醒也有的技能，再显现特殊能力。亲情守护通过行动与生父形成反差；不用把养父线改成恋爱。来源1-3、4-2/4-3、5-1。

**正文与分析冲突**：

- 第2集已经跳崖，第3集又回到崖上对峙，复述／闪回关系未标明；不能当正常时序直接学习。
- 分析称护盾连Alpha也无法突破，正文3-2却写护盾被打碎；优先记录正文事实，标规则疑点。
- 5-1递的是戒指，动作写戴在左耳；不能据此同时建立戒指和耳饰两种魔法物品。
- 原分析把亲情／师徒守护归入“强性张力”，这是标签误用，本包改归亲情反差与归属。
- 分析出现正文未出场的Tiffany、未充分证实的母亲后续经历；只列为分析中的说法。末段“每30分钟小情绪冲击”是疑似数字错漏，不擅修成30秒引用。

## C03《The Abandoned Baby Girl They Could All Hear》：心声必须改变别人行动

**范围**：第1—3集正文，267行，含未取得的截图引用；标题带“分析”，可读文本实际主要是正文。

**正文链条**：婴儿身体和成人意识反差 → 国王、王子能听见其心声而她未充分掌握这一点 → 心声指出伪善角色与未来危机 → 第3集Julian听到戒指线索，以拿回礼盒作试探 → 戒指落地，认知变成可见证据。来源1-1—1-3、2-1、3-1（L239—265）。

**可迁移**：超能力不要只供吐槽；使听者改变判断和行为，再用道具检验判断。区分婴儿内心、旁人的私有内心及可听对白，建立能力接收范围。

**需纠偏**：第1集OS说熬夜看书昏倒，闪回却是领奖时倒下，关系不清；第3集“他能听到我的心声吗”标在Julian名下，与当前知情链有疑点。不能无视这类错标，把角色变成全知。第3集到戒指落地结束，指控如何兑现未提供，不补造下一集。

## C04《疯美人》：道具从逃生资源转成身世筹码

**范围**：前10集的逐集概述和分析，非完整剧本；不能把作者评价“无注水”当实测结论。

**链条**：第1集以父亲死亡与女儿认杀的结果引出因果谜；第3集黄金给逃生条件，玉佩把问题引向身世；第6集母亲将玉佩传给女儿；第8集女儿用纹饰作谈判筹码；第10集与车马纹饰匹配，推动寻亲方向。来源各集事件段（第3集L61—75、第6集L127—143、第8集L175—191、第10集L221—237）。

**可迁移**：同一物件在不同阶段承担资源、情感、交易与辨认证据功能；每次转换都要有持有／展示行动。女主不仅受苦，还观察、撒谎、谈判并寻找机会。

**需纠偏**：这是国内背景案例，只能迁移功能，不能直接当海外市场证据。连续虐待和监视段有重复压迫风险，不能因分析称快节奏就要求新稿照做。第1集承诺的杀父因果，在所给10集尚未完整回收，不能称全线闭环。文化置换要重建行动空间和权力条件。

## C05《Came Back Hotter With Lord's Twins》：长线信息差与家庭归属

**范围**：全文第1—50集，3984行，结尾有“The End”。文件名“榜一”未核平台、榜单日期、数据，不能作为成功率证据。全部逐集核对记录见 [50集映射](case-twins-map.md)。

| 范围 | 主要状态变化 | 可学方法 |
| --- | --- | --- |
| 1—3 | 受弃相遇，五年后女儿被绑迫使返城 | 用具体损失建立稳定行动目标 |
| 4—14 | 被迫联姻，救援重逢，身份仍错认 | 同一目标串联家庭与感情线；观察者与角色知情分开 |
| 15—22 | 双娃换位，性格差造成破绽 | 两个孩子先有不同欲望和恐惧，换位才产生信息 |
| 23—28 | 前夫绑架后获救，婚前误会继续 | 小救援可兑现；过强身份线索不应让角色停止调查 |
| 29—37 | 保护被误读，婚礼中止，孩子被掳 | 误会应来自可解释的局部观察，不能无限拒绝求证 |
| 38—45 | 诱杀、救娃、相认、抓捕与旧事解释 | 道具细节改变判断；孩子解释使误会得到具体纠正 |
| 46—50 | 私下相认转为公开身份和族群接纳 | 结局回应开头无家可归，并以公开承担代价兑现承诺 |

**可复用工作法**：

- 主角行动指向救女：绑架信3-6 → 返城4-3 → 夜探8-1 → 为保女公开生育史13-2。
- 双娃各有心理：Bella敢保护母亲，Kathy渴望安全；15—19集换位后产生不同生活反应，40—41集行动与解释改变结果。
- 反派随证据换策略：阻止出行7-1 → 压制孩子11-3 → 囚禁35-1 → 诱杀38—39。每次升级追问她要保住什么。
- 关键道具记录“谁持有—谁看到—相信什么—怎么行动”：信件3-6、针17—18、照片22-1、衣裙与剑38-1。
- 配对检查钩子：24破门→25解缚；40制止恶徒→41救娃相认；48血脉曝光→49群体施压→50承担选择。
- 家庭日常也产生新信息：19-1孩子替父亲说话、母亲察觉不同；不是纯糖水。

**不能照抄**：27集已经有很强的身份线索但调查长期停滞；31—34集男主误判后的伤害不能用一句“误会”或反派背锅完成修复；药物影响下的亲密不能当清醒同意范例；女主有强能力但经常无说明地失效。结尾的家庭接纳已兑现，偷婴链、反派公审、前夫追责和部分能力限制未完整解释，不能声称全闭环。

**转录质量**：多处双胞胎错名、城市拼写漂移、剑的材质混用；32-2“多年后”与当天婚礼冲突；43-1认出Jodi却误写Melody；部分声音标记会改变谁已知情。需核原视频的疑点不能当创新设定。

## C06 未命名第1集：假死亡证据与重逢的双线期待

**范围**：只有第1集四场，77行。Jane为救Darius受威胁离开；Natasha告知男方她采药坠亡，头簪被用作死亡暗示；七年后男方怀念，另一边两个孩子推着病母求医，两车相遇后停在相认临界点。

**可迁移**：同一道具连接虚假结论、持续思念与时间跨度；对照人物已知事实制造等待；大场面必须围绕“为谁作何选择”。来源1-1—1-4。

**需纠偏**：1-1 L13请求太后救人一句被标为Natasha，与求救者上下文疑似不符；1-3人物表未覆盖实际护送卫兵。头簪只能提示曾属于谁，不足以逻辑证明死亡；如果角色因此确信，须展示其信息限制。第2集未提供，重逢兑现未知。

此片段与C05只有龙族、失散与萌娃重逢等类型相似，人物、分离机制、时间跨度和事件不同。没有版本证据不能互认同源或交叉补剧情。
