# 九类题材工作卡与萌娃分型

以下是对 T01—T09、I01 的编辑性浓缩；题材机制源于资料，检查问题、成本取舍及避坑由本包归纳，不是市场验证结果。按主冲突选相关卡片，不需每次全部加载。图表中的地区推荐全部保留为原资料假设，不能据此保证受众偏好。

## T01 禁忌情感：克制、选择与代价

- **承诺**：相互吸引但不能轻易靠近，最终以真实代价换取自主选择。来源§核心特征、创作原则，L11—25、131—157。
- **角色与阻力**：有独立目标的成年人；职业边界、无血缘家庭身份、年龄／圈层差、上下级利益或宿敌阵营造成持续阻碍。资料细分见L27—91，不把这些组合自动认定为符合任何平台尺度。
- **推进**：被迫协作或接触 → 短暂互认／保护 → 秘密暴露威胁 → 名誉、事业或阵营代价 → 可见的站队与安排改变。
- **回报与钩子**：一次尊重边界、冒险保护、公开承担损失就是关系回报；偷拍、最后通牒、立场二选一须在后续改变行动，不能只写“差点亲上”。
- **易失效**：阻碍凭空消失；克制角色无理由失控；用职权、债务或魔法代替同意；只有暧昧没有其他人生目标。亲密关系须核角色成年、选择清楚；资料“触碰即下架”不是已核实规则。
- **制作／本地化**：有限办公／家庭／宴会空间可承载张力，重点是动作与权力后果；具体职业制度和地区文化另核，不用“北美都接受”作理由。

## T02 重生复仇：每项旧损失对应一次夺回

- **承诺**：将先知优势变成行动，夺回资产、成果、名誉、机会或生活自主。来源§六类人设、分阶段模板，L23—149。
- **角色与阻力**：重生在损失发生前的可操作窗口；反派掌握资产、关系或公众信任。主角记忆可以指出方向，却不能自动成为今生可公开的证据。
- **推进**：记清前世损失 → 阻止第一笔损失 → 积累证据与资源 → 拆反派联盟 → 反派适应／未来改变 → 清算并关闭旧账。资料“60—100集”标题与只到60集的模板不一致，保留阶段，不照抄集号。
- **工作表**：`旧损失｜责任人｜当下行动窗口｜资源／证据｜反派应对｜今生代价｜兑现状态`。
- **回报与钩子**：产权或成果归属改变、伪证被拆、合作翻转；“这只是开始”不是具体钩子，改为下一项证据或即将到来的行动。
- **易失效／制作**：全知且没有代价、改命后未来逐字不变、反派无能、复仇无收束；少量前世关键场对照今生选择比完整重拍两条时间线更可控。股权、继承、专利和司法后果按地区核实。

## T03 末世生存：资源优势与道德选择一起兑现

- **承诺**：失去旧秩序后守住人和家，凭能力争得生存条件。来源§类型、角色、节奏、素材库，L13—313。
- **三种环境**：感染与派系；天灾与资源垄断；异能被捕捉利用。挑一个主要系统，不每集换灾难。
- **角色与阻力**：保护家人的医护／母亲、背负失败的工程师等，以有限库存、技术或免疫能力对抗控制资源者。队友各有知识贡献与利益。
- **推进**：明确资源缺口 → 抵达控制点 → 必须取舍 → 用已建立的能力临时解局 → 获得物资／信任 → 优势暴露导致新风险。每次胜利应留下成本或新的责任。
- **爽点库**：水、药品、燃油、种子、电力、通信与交通改变行动范围；不是一律消灭更大怪物。钩子可为据点有诈、优势招来追捕、代价即将兑现。
- **易失效／制作**：无限库存、无代价抗体、反复背叛而信任无法增长；固定基地、门外声响、广播、储量显示可替代无功能灾难奇观。医学与技术桥段只写剧情功能，现实精确事实另核。

## T04 魔法奇幻：力量改变资源、阶级和选择

- **承诺**：被低估者以受限的能力取得尊严与地位。魔法要服务钱、权、爱或复仇。来源§一—四，L13—117。
- **角色与阻力**：无魔力／弃女／退婚者与决定资源的测试、世家、学院对抗；伙伴提供互补能力，不包办胜利。隐藏能力之外仍要有技能、策略或信念。
- **推进**：公开测试或剥夺 → 小能力打破一条旧判断 → 取得资源并遭质疑 → 代价／反噬 → 大揭露 → 更大责任。提前定义规则的触发、限制、代价和知情者。
- **爽点**：读心揭伪、治愈交换资源、规则反制、公开力量证明。能力增加必须带来行动变化；镜头里的光更大不等于剧情升级。
- **钩子**：图腾暴露、法术突然失效、契约将解除、觉醒引来外敌。来源给多组互相不同的秒数／集数，均不用作硬指标。
- **易失效／制作**：血统替代所有成长，临时开挂，男主无条件解围，反派不应变；用稳定少量法术视觉与可重复场景承载规则。契约共享痛觉不等于共享亲密同意。

## T05 萌娃亲情：孩子有自己的弧光

- **承诺**：弱小者被珍视、家庭修复、童真与能力的反差；可以是温情日常，不必都是豪门认亲。来源L25—99，独立图片I01。
- **三种主线**：被构陷后母亲离开与成长，孩子帮助揭真相；弃儿被收养后逐步建立归属；意外／隐瞒造成失散，重逢后修复。先定成人责任，不能用孩子强迫受害一方复合。
- **能力分型**：财迷、毒舌、天才、暖心、护母、好运各承担不同功能。读心型记清谁听得到谁的心声；成年人心智穿越成婴儿仍要表现身体与表达限制。
- **推进**：孩子有自己的害怕／愿望 → 采取符合能力的行动 → 改变大人的信息与选择 → 获得被相信／被照料的回报。相认不能直接代替信任修复。
- **易失效**：全能儿童、成年人持续失能、孩子只负责撮合、只升级虐童；本地化另核监护、学校与家庭称谓。真人制作需考虑儿童表演与拍摄安排，不能直接视为低成本。

## T06 赛博未来：技术应改变人的选择

- **承诺**：底层争取资源、身份与自主，对抗技术和阶级垄断。来源L13—143。
- **五种机制**：上下城空间隔离；巨企垄断水／氧／寿命；义体与记忆交易；虚拟世界与意识上传；黑市赏金与竞技。选最能支撑主角目标的一种。
- **人物与推进**：黑客和猎人互缺能力，或失忆士兵追查过去；新权限 → 实际胜利 → 授权方／企业察觉 → 使用代价 → 身份和忠诚选择。每次升级说明能做什么、失去什么。
- **回报与钩子**：夺回控制权、恢复一段能力、识破亲情幻象；虚拟现实反转须有前证且不抹消角色关系的投入。
- **易失效／制作**：霓虹皮肤、无限黑客、搭档无用、最终“一切都是假的”；用固定层级空间、局部义体和稳定接口道具展示制度，视觉一致性先于堆机甲。资料的欧美／中东／东南亚偏好仅作候选假设，不移植商业IP专名。

## T07 亿万富翁／黑帮：力量有效，关系逐步平等

- **承诺**：危险环境中的选择性保护、对外强势对特定人克制，最终让渡控制。来源L11—80。
- **人物与阻力**：女主有债务、家族或生存困境，也有独立目标与判断；男主权力有来源及边界。合法企业与犯罪集团分开设计，不因有钱就默认黑帮。
- **推进**：利益绑定 → 互探底线 → 危机中双方贡献 → 旧仇／家族冲突 → 放弃一项控制或利益完成关系变化。
- **回报与钩子**：一次尊重拒绝、改变不平等条件、公开承担成本；条款变化、保护暴露身份、利益与爱人冲突可产生下一步行动（这些钩子为本包推导）。
- **易失效／制作**：每次一个电话解决、所有越界都叫保护、女主只负责感化；权力可用他人响应、关键场景与行动结果表现，不必每集豪车枪战。关系升温需双方可选择，债务不能代替同意。

## T08 奇幻罗曼史：靠近越深，代价越真

- **承诺**：相爱触发法则冲突，双方共同改写命运。主驱动力是关系，区别于T04的能力／地位逆袭。来源L17—91、119—152。
- **角色与规则**：超自然者有力量也有缺陷；另一方的独特性来自能力、判断或共同经历，不能只有“身体是解药”。契约、寿命、阵营、前世或神罚须清楚定义。
- **推进**：相遇／绑定 → 共同应对代价 → 一方觉醒改变权力平衡 → 信任与阵营危机 → 双方作出有成本的选择 → 利用已建立规则解决诅咒。
- **回报与钩子**：高位者收敛、弱势方主动救援、真正信任；魔法反噬、旧物触发记忆、承诺引来惩罚。每次亲近要留下一项关系变化，不能不断复位。
- **本地化**：修仙→魔力、宗门考核→学院试炼、天劫→反噬只是功能候选，仍需补机构权力和行为后果。“Fae仅次狼人”不作为市场事实。
- **易失效／制作**：不断强制贴近、女主工具化、万能爱破解一切；固定契约纹样与圣物便于视觉连续。参考C01可学习“照料也增加代价”，不能把失控写成侵犯的免责理由。

## T09 西式神话：先选母题，再建本剧规则

- **三类素材**：希腊罗马的神权、半神、预言与冥界；北欧的末日、敌对阵营与诅咒；暗黑宗教幻想的灵魂契约、堕落与救赎。来源L13—85。
- **承诺与推进**：凡间困境 → 记忆／神格觉醒 → 发现旧背叛 → 对抗神权执行者 → 承担改变规则的代价。神名不代替动机，神罚必须有具体执行方式。
- **方法**：传统母题、现代商业改写、本项目原创分列；改写可融合，但不把融合结果称为原典。资料列举的若干英文剧名、平台归属和热度未核验，不用作已验证对标。
- **易失效／制作**：堆神系和名词、把娱乐反派等同现实宗教、抄商业作品独特表达；现代小镇觉醒、少量圣物可承载关系冲突，世界大战只有在主线需要且制作可承担时展开。

## 混合题材检查

写下“没有副类型，主角的哪项选择会不同”。回答不了就先不用。对标学的是限制、知情差、代价和兑现方式；换人物名照搬事件串不是机制迁移。尺度与文化判断按实际项目，资料中的激烈内容是分析对象，不自动成为新剧必选元素。
