# 正文与本地化工作约定

此文件补充海外资料中的具体方法，并在既有专业模块缺失时提供可执行的基本流程。已安装时优先读取 `em-outline-to-script`／`em-us-localization`，本次任务约定覆盖模块默认受众、语言、体量与制作方式。这里只做文化与正文方法，不冒充目标平台的现行格式规定。

## 由集纲写正文

1. 从已定集纲锁定人物、时间地点、按序事件、动机、道具与证据、情绪转折、知情范围、集尾。原创任务同时授权设计集纲时可先完成；仅扩写任务不新增重大事件填空。
2. 把每个事件写成可见可闻的行动与反应：谁想阻止谁、使用何种条件或资源、对方如何应对、局面有什么变化。
3. 对白表达目的而非复述画面。保留必要信息，用命令、拒绝、试探、交易、隐瞒、揭露等具体动作承载情绪。短句有用，但不机械逐句重复角色名。
4. 连读本集与相邻集，检查事实、说话人、内心是否被误当公开信息、道具持有者与结尾。完整交付指定范围，不用样例替代全批。

中文默认制作稿示例（只是格式，不是固定情节）：

```text
第3集

3-1 夜 内 书房
人物：艾拉、诺亚、管家（电话音）

△ 诺亚压住桌上的信封。艾拉没有松手。
艾拉（压低声音）：先告诉我，这封信是谁给你的。
```

每场标题后第一条非空内容独立写 `人物：……`。按实际出镜、发声与功能角色逐场核对，电话／VO及照片素材注明方式，纯提及者不列；空镜写“无”。同一角色没有动作、他人回应或声音模式切换打断的连续对白合成一段。只在影响读法处加简短可演的情绪提示，不每句机械加括号。

## 两种格式配置分开

G02同一文档包含中文制作稿与英文 spec 建议。指定模板优先，不将英文 spec 的页面尺寸、黄铜装订钉或镜头禁令强塞入中文电子稿。

| 项 | 中文制作稿 | 英文交付 |
| --- | --- | --- |
| 场头 | 集场编号、日夜、内外、地点 | 按接收方模板，一般可用 INT./EXT. 地点 - DAY/NIGHT |
| 人物行 | 本套件默认每场单列 | 有明确英文模板则按模板；无模板时沿用明确的场次出场信息 |
| 动作 | 可见可闻，动作与对白分开 | 简洁现在时；是否保留镜头指令按稿件用途 |
| 声音 | 明写内心、电话音、画外音，避免歧义 | O.S.通常用于同场画外发声，V.O.可用于旁白等；按项目约定明确实际发声位置 |

不能把中文惯例中的“OS内心”直接替换成英文“O.S.”。先识别声音到底发生在哪里、谁听得到，再按目标模板编码。新角色进入连续场景不自动产生新场号；场次划分按时间、地点和项目实际约定。

## 本土化：功能映射而非换名

依据 G03/G05，记录：

`原元素／原动机｜提供的权力或证据｜情绪功能｜目标文化候选｜是否改变事件或关系｜所需授权／事实核验｜选定映射`

例如宴席羞辱可在适合本项目时改为当地的公开社交场合，但不能凭空把私事改成法院能直接裁决的案件。战神→Alpha、宅斗→王室继承仅是创意候选；必须重建权力来源、继承规则、能力边界和对手策略。奇幻西式外观不等于真实美国文化。

在授权范围内统一姓名、称谓、地理、金钱、机构、通信、生活细节和世界术语。保留角色族裔与背景的合理多样性，不默认全员白人或加州人。精确医疗、司法、财产、警务与价格细节查目标地区权威资料；不能核实的留待核，不照抄指南举例当事实。

英文先确定说话目的、事实和情绪强度，再用该人物会说的表达重写；自然度不能以新增威胁、关系或证据换取。既有美国背景只需英文润色时用 `em-english-polish`，不重做文化改编。

## 制作适配

真人：标识群演、动物、危险动作、夜外、儿童、特殊场景及特效成本，给保留故事功能的替代选项；不凭空估真实报价。AI：按当前工具判断角色一致性、多角色互动、复杂手部／接触、道具连续性和跨镜头成本；G05“减少复杂走位”是生产启发，不是模型永远做不到的事实。仅在已授权维度落实调整，不能为了省成本换掉关键线索。
