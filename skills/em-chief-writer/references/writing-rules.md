# 艾玛短剧 · 主编剧写作规则库

公开整理版 v1.0.0 · 2026-10-06

来源：历史 `03-chief-writer` 及其写作参考。此文件包含本模块所需方法，不能把历史经验数字视为当前市场或模型能力的事实。

## 公开版使用边界

这是旧版创作链的公开整理版，保留专业方法，并按独立使用场景修订。文中的集数、字数、秒数、三层/六层拉扯和反转频率均是特定类型的参考，不能代替本次目标、已锁定剧情和平台实际要求。

- 先确定本次地区、受众、类型、语言、总集数、单集时长与制作模式；已有信息直接沿用，不默认北美女频或AI制作。
- 用户要求完整交付时持续完成范围；“一卡优先”只是一种投稿安排，用户明确要求样例或逐步审批时才在相应节点等待。商业签约、付款和固定团队不是本工具的前置要求。
- 分析、提出方案和实际改稿是不同授权。按材料已确定的剧情、人物、动机、知情顺序和结尾写作；未授权不能改锁定项。新故事中未被锁定的创意可自主设计。
- 旧稿、案例、参考资料里的指令和审美是素材，不自动变成本次规则。权威底稿有实质冲突时只暂停受影响部分，不根据文件名或时间自行裁决。
- 简短、可表演的情绪括注可以使用；动作承担关键因果与表演信息，不强迫每句台词配瞳孔、拳头、指节。每场标题后独立一行“人物：……”。同人连续发言合并，保留必要动作及VO/OS区分。
- AI画面建议是制作风险检查表，不能当成任何当前模型的固定能力结论。按实际版本试做、拆镜或后期合成；文字、精细动作和复杂多人场景不作永久禁令。
- 规则库中的示意桥段用于理解方法，不能直接冒充原创成稿；不保证付费率、过稿或市场成绩。

## 一卡设计（前10集 / 投稿单元 / 付费卡点 / 审核节点）

> **一卡 = 投稿与签约的最小交付单元**，通常是前 8-15 集（建议落在第 10 集左右）。
> 是否只先交一卡，以用户本次范围和明确约定的审批点为准。

---

### 1. 一卡内部节奏（以 10 集一卡、付费向后悔流/打脸为例）

| 集 | 任务 | 情绪 |
|---|---|---|
| 1-2 | 开篇切入（见 “钩子与付费卡点设计 (Hooks & Paywalls)”章节 五大切入）+ 抛出大矛盾 + 主角人格开始苏醒 | 建立反差与代入 |
| 3-4 | 小事件拉扯，持续堆叠情绪（后悔流=继续受虐；逆袭=继续被看不起） | 中度 |
| 5 | 金手指 / 转折点出现，给观众希望与期待（决心离婚、发现搞钱门路） | 希望 |
| 6-7 | 在新条件下产生新摩擦，持续拉扯 | 升级 |
| 8-9 | 尖锐大矛盾爆发，第一次用金手指打脸 | 高 |
| 10 | **全剧第一个超大卡点**（断亲/离婚/离开/身份揭露/绝症大祸/大反转），戛然而止 | 顶点 |

> 节奏是参考不是铁律：免费向一卡可更轻快、梗更密，但钩子也要足；付费向一卡矛盾更尖锐、更重情绪收割。
> 用三个"小故事点"撑起一卡的情绪升级（见 “情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账）”章节 的"轻度→中度→重度"）。
> 例（家庭逆袭示例一卡三小故事点）：偏心不分钱(5分) → 借3千被拒转头给哥买车(7分) → 1.5万彩礼被挪用给外人娶妻(9分)。

---

### 2. 开篇检查（以三集为参考）

开篇尽早完成、且让观众明白"这部剧讲什么"并产生期待：
- [ ] 人物出场（控制首次出场信息量，按剧情需要引入）
- [ ] 核心矛盾建立
- [ ] 主角目标 / 自我意识觉醒
- [ ] 有强吸引力的开场（前1-2分钟抓人，见 “钩子与付费卡点设计 (Hooks & Paywalls)”章节）
- [ ] 信息点不要倾倒：只交代与当前冲突最相关的身份/关系；童年往事等用后续闪回逐步给

---

### 3. 卡点怎么写（=情绪积累到顶点的爆发 + 悬念）

1. **堆积情绪**：靠前几集的打压/委屈/矛盾，把观众的愤怒、憋屈推到高点。
2. **主角关键抉择/行动**：在情绪顶点说出决绝台词（"我们离婚吧"）、关键反击、或身份面临暴露。
3. **留悬念定格**：用一个强画面或强台词定格结束本集（"什么？！"几人震惊表情拼一个画面）。

卡点既是旧压抑状态的终结，也是新阶段（如追妻火葬场）的开启。

常见卡点类型：断亲决裂、离婚/离开、身份揭露、绝症/大祸、大反转。

---

### 4. 字数与钩子不同步时（一卡内尤其要处理干净）

- **字数不够一集**：钩子前剧情若重要，就丰富细节/加凸显人物的小互动凑足，把钩子放本集结尾。
- **字数够了钩子没到**：剧情若平，精简压缩把钩子提前；剧情都重要，则在此设一个**假钩子/小悬念**收尾，真钩子放下一集开头。
- **切忌在平淡处断集**。一卡前最好写完再精简到字数要求。

---

### 5. 真钩子 / 假钩子（贯穿一卡与全剧）

- **真钩子**：观众最想知道答案的核心问题，贯穿全剧，是灵魂。一卡里要立住 1-2 个。
  - 例：女主何时真正离开？马甲/身份何时掉？男主何时发现女主是恩人？
- **假钩子/假卡点**：单集内可多次出现的小反转/小悬念，可切片用于投流。多多益善，但别削弱或混淆真钩子。
  - 后悔流假钩子技巧：让男主反复接近真相又错过（拿起离婚协议→电话响放下→翻一页→管家敲门→第三次终于看完，女主已走）。会"激怒"观众，但正是追剧动力。

---

### 6. 付费 vs 免费 一卡区别

| | 付费向一卡 | 免费向一卡 |
|---|---|---|
| 类比 | 短篇小说（免费段要精彩到让人掏钱） | 番茄长篇（整体质量在线） |
| 写法 | 强情绪、强卡点，矛盾尖锐，注重付费点收割 | 可更轻快、梗密集，降低观看门槛，但钩子要足 |
| 付免双跑 | 开局强情绪切入（吸付费）→ 中段轻喜（提免费完播）→ 卡点回强情绪 | 按项目要求确定 |

---

### 7. 一卡审核 checklist（按实际交付范围使用）

**一卡集纲检查**：
- [ ] 选题与本次目标、交付范围一致
- [ ] 核心真钩子明确（一句话能说清观众最想看什么）
- [ ] 第10集左右的超大卡点已定，且情绪能撑到顶点
- [ ] 三个小故事点呈"轻→中→重"升级，无翻旧账重复
- [ ] 前三集硬性要求齐全

**一卡正文检查**：
- [ ] 前1-2分钟开场抓人
- [ ] 每集结尾有钩子，第10集是最强卡点
- [ ] 台词通过 “台词引擎（一句一功能 / 信息去重 / 四技 / 压缩流程）”章节 自检（一句一功能、无重复）
- [ ] 情绪逐层升级（“情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账）”章节）
- [ ] AI仿真人项目：视觉标签/转场/细节达交接要求（“AI仿真人剧写作法（区别于漫剧 / 真人剧）”章节）
- [ ] 字数符合题材+付费模式（“分集撰写要求与自检清单（通用，按生产模式调整）”章节），不僵硬

## 台词引擎（一句一功能 / 信息去重 / 四技 / 压缩流程）

> 优秀爆款的三标准：选题吸引力、情绪共鸣、**台词功底**。
> AI仿真人剧台词不宜多，更要"一句顶一句"。本文件是台词层的可执行规则与自检。

---

### 1. 核心原则：一句台词一个功能

**避免无意义重复，每句台词都提供新信息或推进情绪。不要在同一层面来回说同一件事。**

技术指标：5号字体下台词超过 3 行就太长，需精简或加气口；每句必须回应上一句、并有新进展。

一句台词可承担的功能（同一段对话里轮换，不重复）：
警告 / 反驳 / 亮明目的 / 道出背景 / 犀利拒绝 / 威胁升级 / 羞辱 / 嘲讽 / 揭示信息 / 下达态度。

**一字之差，人设天壤**（先想清楚此刻角色是强势还是弱势）：
- "你**果然**背弃了誓言" → 主角是掌控者，居高临下。
- "你**竟然**背叛了我们曾经的誓言" → 主角是受害者，弱势。

---

### 2. 信息去重：哪些不能重复，哪些可以/需要重复

**同一集内不可重复**：用不同台词反复说同一个事实（如"你们不关心我""要八十万"说一次就够）。

**可以/需要跨集重复（用于持续刺激）**：
- **核心罪证**：反派做过的某件恶事，可在不同集、由不同人、在不同情境下提起。
- **人物核心标签**：如"她是扫把星""他是窝囊废"，多次事件强化，为打脸铺垫。

**信息点叠加=递进，不是并列**：骂人→推搡→毁坏重要物品→牵连亲人。每个新打击点要引入新信息、触及新痛点、把矛盾推向更激烈维度。

---

### 3. 四大台词技巧（附公式）

#### 技巧1：对比法（抬高一方、贬低另一方）
公式："你连 ___ 的一根头发都比不上" / "虽然你 ___，但 ___ 才是 ___" / "真 ___，不像 ___，云泥之别"。
- 例：女儿为女配精心准备生日礼物，却记不住妈妈生日。
- 例：父母把拆迁款分给大哥小妹，唯独不给男主，还说"为你好"。

#### 技巧2：故意曲解 / 冤枉法（扣帽子）
把对方的正当诉求恶意歪曲，激化矛盾。
- 女主说"我想离婚" → 男主："你就是想跟那个野男人跑吧？"
- 女主说要工作 → "你就是想勾引老板。"
- 女主穿廉价衣服 → 女配说她"卖惨心机，想让男主心疼"。

#### 技巧3：PUA法 / "我都是为你好"
施害者站道德制高点，让受害者有苦说不出，极易引爆观众愤怒。
- "你入赘刘家能少奋斗三十年。"
- "你弟弟是咱家命根，你不帮他谁帮他？我们养你这么大容易吗？"
- "大嫂怀的是你大哥的遗腹子，我救她不应该吗？你就不能体谅体谅我？"

#### 技巧4：金句法（高潮/觉醒/反转时点题升华）
配方：对仗俗语 / 具象比喻 / 价值观反转 / 递进排比喊话观众。
- "靠山山会倒，靠人人会跑。"（对仗）
- "我住在你的家里，我的灵魂却没有出口。"（意象）
- "爱不是束缚，应该是托举。" / "真正爱你的人，什么也不会让你放弃。"（价值观反转）
- "为了自己，为了天下女子，更为了被看轻的黎民百姓！"（递进排比，可标注"音乐燃一点"）

> 平时刷小红书/抖音评论区收集有共鸣的金句，建立金句素材库。

#### 反派话术库（按功能取用）
当众捧高踩低羞辱 / 把正当行为曲解成出轨被收买 / 以退为进扮无辜PUA / 用"恩情+牺牲感"道德绑架 / 把努力污名化成"偷学、爱出风头" / 用"办正事"虚装公正掩盖偏心。

#### OS / VO 用法
用内心独白替观众点破潜台词，一句完成"揭示信息 + 扎心"双功能。
- 示例：角色OS只点出当前可知的隐情，不替观众解释每个动作。

---

### 4. 台词压缩流程（保护信息与因果）

**步骤**：
1. 标出每句的功能（警告/反驳/目的/背景/拒绝/威胁…）。
2. 找出功能重复的句子（多处"不关心我""八十万"），**只保留一次**。
3. 把多处背景信息**融合进一句**台词。
4. 确认每句都有新进展，呈链条：警告 → 反驳 → 目的 → 背景+拒绝 → 动作 → 威胁升级。
5. 删掉长篇心理描写，转成简短有力的动作或对话。

**公开版示意**：把反复说明“你从不守时”的争论，改为“我等过你三次。这次我先走。”具体采用哪一句，必须核对当场事实，不能凭空新增三次失约。

---

### 5. 吵架推进 = 回合制层层升级（不是重复对骂）
情绪不对，往往是冲突层次不够、只在表面争吵。设计冲突时**不要一个回合结束**，要多个层层升级的打击点，句句戳心、有来有回。
（具体的多层结构见 “情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账）”章节 六层拉扯。）

---

### 6. 台词自检 checklist
- [ ] 每句都有独立功能，没有同层面重复
- [ ] 同集内同一事实没被反复说
- [ ] 跨集重复的只有"核心罪证 / 人物标签"且每次有新情境
- [ ] 用上了对比/曲解/PUA/金句中至少一种（按场景）
- [ ] 强弱势定位正确（一字之差检查）
- [ ] 长心理描写已转为动作/对话
- [ ] 单条台词 ≤3 行（5号字），过长加气口或拆分
- [ ] AI仿真人项目：背景信息尽量交给 VO/OS，对话脱水

## 情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账）

> 短剧是"卖情绪"。情绪不够强，几乎都是**冲突层次不够 + 升级不够 + 延迟满足没做够**。
> 本文件把"情绪"从抽象词变成可检查的结构。配合 “台词引擎（一句一功能 / 信息去重 / 四技 / 压缩流程）”章节（台词层）与 “冲突设计与爽点策略 (Conflict Design)”章节（爽点/反派层）使用。

---

### 1. 情绪逐层升级：轻度 → 中度 → 重度（每个新事件更狠、更戳心）

家人/反派的态度与行为要**越往后越过份**，从小转大。
- 例（家庭逆袭示例 与父母冲突）：偏心不分钱（轻度）→ 连3千都不肯借（中度）→ 把1.5万存款借给外人娶妻（重度）。

主线上的两条"升级线"要同步往上走（后悔流/逆袭通用）：
- **打压/后悔线**：看不起 → 开始后悔但嘴硬 → 彻底悔恨求饶。
- **事业/反击线**：数字看得见地变大（打工赚4万 → 开网店赚100万 → 房地产赚数亿）。

> 长篇用"故事点"换续航：70集约3个大故事点；80集再加一层（赚钱插一层、后悔插一层）。

---

### 2. 六层拉扯法（大卡点前设6个层层递进的小冲突）

在一个大卡点之前，设计 **6 个比前一个更激烈的小冲突**，每个都提供**新信息或新冲突方式**。
吵完一个点就过去，进入更狠的下一个——**绝不翻旧账、不重复**。

**模板（家庭宴会示意大卡点前）**：
1. 身份打压（"你没资格参加宴会"）
2. 上升到肢体（要打女主）
3. 新人物介入激化（男主不分青红皂白护短）
4. 颠倒黑白（女主的功劳给女配）
5. 抢走重要物品（妈妈遗物被抢）
6. 逼下跪后出尔反尔（下跪后对方却摔了遗物 → 顶点）

**模板（幻想宴会示意大卡点前，幻想题材同样适用）**：
1. 羞辱被退婚、没资格来天后宴
2. 羞辱资质平平配不上
3. 男配登场不分青红皂白攻击女主
4. 羞辱女主怀里抱金蛋（私生活混乱）
5. 女配假意示好实则冤枉
6. 攻击女主母亲是狐狸精、父亲可能已死（最戳心）

**层级走向参考**：骂人 → 推搡 → 毁坏重要物品 → 牵连亲人。是递进，不是并列。

---

### 3. 禁止翻旧账（情绪连贯且升级的铁律）
- 每个新事件必须比上一个更激烈、更戳心，且带**新的信息点**。
- 不要在同一层面重复冲突；不要靠反复回忆旧委屈凑情绪（旧委屈用闪回在卡点集集中堆叠升华即可，见 “分场正文格式”章节 闪回用法）。
- 编辑常批"冗长啰嗦"，根因就是反复强调反派过分之处而无新进展。

---

### 4. 后悔流双曲线（感情线 × 事业线，方向相反）

```
情绪/状态高度
  │  女主感情线（短）：高起点 → 一路下滑 ……↘
  │                                    ╲      ↗ 男主感情线（长）：低起点 → 缓慢上升
  │  女主事业线（长）：低 → 持续上升 ↗   ╳  ← 两线在"矛盾激化点"交叉（关键卡点）
  │                              ↗     ╱ ↘ 女主感情触底→决心离开
  └────────────────────────────────────────► 时间/集数
                 触底后女主"觉醒"，事业线陡升
```

- **女主**：感情起点高（深爱）→ 经历矛盾一路下滑；同时**事业/自我意识线上升**。
- **男主**：感情起点低（冷淡/厌恶）→ 随女主感情下滑、事业上升而**缓慢上升**；直到女主触底（决心离开）才真正觉醒。
- 事业成功不只是打脸，更是让男主刮目相看、感情升温的催化剂。
- 成长型人设：女主快速振作逆袭，但即使事业成功，仍会在意"他为什么还这样对我"——这种纠结才真实。

---

### 5. 延迟满足（后悔流能火的底层）

受众多为生活中隐忍的女性，核心需求不只是打脸，更是**诉说委屈**并获得（剧中）男性的后悔与认可。
- **细致刻画女主的付出与委屈**（用具体日常细节："我每天五点起床做饭，你吃过一次吗？"比大道理更共鸣）。
- **延迟满足**：男主不能很快后悔，要一点点积累，**大结局前才彻底爆发**。
- 两个交替悬念维持张力：A 男主何时发现女主要离开？B 女主何时真正离开？（配合假钩子，见 “一卡设计（前10集 / 投稿单元 / 付费卡点 / 审核节点）”章节）

---

### 6. 人设要"贴近现实的矛盾体"，不要纯脸谱
情绪起不来，常因人设太极端脸谱化。
- 纯粹的坏人（又穷又丑又家暴）< 更贴近现实的矛盾体（"我爱你，但我妈不同意"的妈宝男）。
- 反派要"又当又立"才更引发代入和愤怒。
- 共情训练：写之前把自己代入受众，"换成我会怎样"——你痛了，观众才痛。

---

### 7. 情绪自检 checklist
- [ ] 每个新冲突比上一个更狠，且有新信息（无翻旧账）
- [ ] 大卡点前铺了多层（理想6层）递进拉扯
- [ ] 后悔流：感情线↓ 与 事业线↑ 反向，且在卡点交叉
- [ ] 男主后悔被延迟到结局前才彻底爆发
- [ ] 女主委屈用了具体日常细节，不是空喊
- [ ] 反派/家人态度呈轻→中→重升级
- [ ] 人设是可信矛盾体而非纯脸谱

<a id="rule-4"></a>

## 分集撰写要求与自检清单（通用，按生产模式调整）

> 适用 AI仿真人 / 真人 / 漫剧 三种生产模式。带"漫剧核心"标注的小节为漫剧专属；
> AI仿真人额外读 “AI仿真人剧写作法（区别于漫剧 / 真人剧）”章节；字数与爽点密度一律按题材+付费模式调整，不套统一硬指标。
> **交稿纪律统一走 “一次通过协议（交稿前自查 SOP，降低返工轮数）”章节（五格状态卡/结构门/敌对审读/提交三件套）；分集信息边界、能动性、语义不混淆走 “真相阶梯、能动性与语义不混淆（继承与伦理规则库）”章节；弧线层 show-don't-tell 走 “漫剧画面写作规范”章节。**

### 撰写流程

#### 写前准备

每次撰写分集前，先确认：

1. **上集结尾**：上一集的最后一个画面和钩子是什么
2. **本集定位**：在全剧节奏中属于什么阶段
3. **本集核心**：这一集要完成什么（核心冲突/爽点/转折）
4. **精细画面预判**：本集有哪些场景需要精细化处理
5. **下集衔接**：本集结尾要为下一集铺什么悬念

#### 撰写步骤

1. 先写本集的节奏骨架（3-5个场次的一句话概述）
2. 标记哪些场景需要精细画面处理
3. 展开每个场次，按漫剧格式规范撰写
4. 检查画面描写是否匹配选定的视觉风格
5. 检查AI画面可行性（有无红灯画面）
6. 统计画面节拍数量
7. 通读确认节奏流畅

### 分集撰写要求

#### 基础要求

- **字数按题材 + 付费模式决定，不是统一硬指标**（关键）：
  | 题材/模式 | 单集字数参考 | 原因 |
  |---|---|---|
  | 后悔流 / 情感细腻向 | 1000-1200字 | 需细腻刻画心理与情绪拉扯，也给AI/演员更准表演指导 |
  | 强情节打脸 / 爽剧 | 500-800字 | 节奏要快、精简 |
  | AI仿真人·需要详细制作交接的项目 | 偏上限(800-1000+) | 要把画面细节写到位供AI直接生成 |
  | AI仿真人·有导演把控 / 真人剧 | 偏下限 | 导演做画面润色，正文更干练 |
  - 平台另有硬性字数要求时（有的5-800、有的800-1000）以平台为准，先问编辑。
- 每集3-5个场次（高节奏爽剧可多1-2场，慢烧可少）
- 严格遵循剧本格式（见 分场正文格式）
- AI仿真人/漫剧：保持AI画面可行性意识（见 AI画面可行性意识）+ 满足交接要求（见 AI仿真人剧写作法（区别于漫剧 / 真人剧））
- 漫剧：遵循画面写作规范（见 漫剧画面写作规范），每集至少1个精细画面场景
- 台词层全程遵循 台词引擎（一句一功能 / 信息去重 / 四技 / 压缩流程）；情绪层遵循 情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账）

#### 画面描写要求（漫剧核心）

- △描写以Show, Don't Tell为铁律
- 每个△段落不超过3行
- 用视觉情绪对照表将抽象情绪映射为具体画面
- 环境描写服务于情绪表达
- 匹配选定的视觉风格美学特征
- 爽点/高潮场景必须使用精细画面拆分

#### 台词要求（详见 台词引擎（一句一功能 / 信息去重 / 四技 / 压缩流程））

- **一句台词一个功能**，避免同层面重复信息（核心原则）
- 单条台词控制在3行以内（5号字体），过长加气口/小动作隔开；爽点台词短而有力、便于截图传播
- 每句台词必须提供新信息或推进情绪，并回应上一句
- 善用四技：对比 / 故意曲解(冤枉) / PUA / 金句；背景信息尽量交给 VO/OS 而非塞进对话
- 不同角色说话方式有区分度（"一字之差人设天壤"，先定强势/弱势）

#### 节奏要求

- 快节奏第一原则（AI仿真人尤其：用快节奏大起大落掩盖表演生硬）
- 跳跃式叙事，不拘泥于场景过渡；大量使用跳切
- 情绪必须逐层升级、不翻旧账（见 情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账））
- **爽点/拉扯密度按题材与付费模式定**：
  - 付费向强情节/打脸：密度高，避免连续多集无推进；
  - 后悔流/情感拉扯集群：可以是"虐点/甜点/拉扯点"而非传统爽点，但每集仍需有新进展或钩子；
  - 判据不是"每集≥N个爽点"，而是"是否连续多集未推进真钩子、无情绪升级"——若是，回看而非硬塞。

#### 精品化写作要求

- 每个反转和爽点必须有合理铺垫
- 角色动机要可信
- 画面描写有构图意识和美学追求
- 台词有记忆点和角色辨识度
- 全程高强度中适当穿插"呼吸感"

#### 固定桥段活用（漫剧特化）

| 桥段 | 漫剧视觉表现 |
|------|-------------|
| 觉醒爆发 | 光芒涌出、瞳孔变色、头发飘起、地面龟裂——用精细画面拆分 |
| 实力碾压 | 一指弹开对方攻击、气浪震飞全场——注重力量对比的视觉反差 |
| 身份揭露 | 印记/纹路浮现、天降异象、所有人震惊后退——强调围观者反应 |
| 进化/升级 | 身体发光变化、外形蜕变、新形态展示——用多个节拍分步展示 |
| 至暗时刻 | 色调变灰暗、环境崩塌、主角跪倒——环境即情绪 |
| 终极对决 | 两股能量对冲、天地变色、终极一击——全剧最华丽的精细画面 |

### 特殊集数撰写指南

#### 第1集：爆炸开场

- 第一个画面就要抓人——漫剧观众比真人短剧观众更没耐心
- 30秒内建立主角困境和视觉奇观
- 建议开篇就包含一个精细画面场景（如觉醒前兆、战斗开场）
- 结尾留超强钩子

#### 付费卡点集（一卡卡点，建议第10集左右；详见 一卡设计（前10集 / 投稿单元 / 付费卡点 / 审核节点））

- 所有铺垫汇聚，前几集情绪堆叠到顶点
- (漫剧)最华丽的视觉场景，建议2-3个精细画面场景
- 主角关键抉择/行动 + 强画面定格，情绪推到最高点后戛然而止
- 这是投稿/付费的关键单元，按本次明确约定的审核节点交付

#### 至暗时刻集（全剧约 2/3 处，集数随总集数缩放）

- 色调和环境描写转为压抑暗沉
- 主角的视觉形象出现变化（受伤、狼狈、力量失控）
- 在绝望中埋下反击种子

#### 大结局集（最后2-3集）

- 全剧最华丽的视觉盛宴
- 终极对决用最多的精细画面节拍
- 所有悬念收回
- 最后一个画面要有"余韵"

### 自检清单

每集写完后，逐项检查：

#### 节奏检查 ✅

- [ ] 开场30秒内引爆冲突？
- [ ] 自然承接上集钩子？
- [ ] 有无拖沓段落（超过30秒无冲突/信息）？
- [ ] 结尾钩子够强？

#### 爽点/拉扯检查 ✅（按题材判定，非硬性计数）

- [ ] 本集有推进真钩子或情绪升级（爽点/虐点/甜点/拉扯点至少一种有新进展）？
- [ ] 强度与全剧进度匹配，且比上一同类事件更狠/更戳心（无翻旧账）？
- [ ] 爽点/卡点前有足够铺垫和压抑（延迟满足）？
- [ ] 没有连续多集毫无推进（若有，回看而非硬塞爽点）？

#### 弧线层 Show-Don't-Tell 检查 ✅（连读最易翻车，详见 漫剧画面写作规范）

- [ ] 有无"作者声称已发生"的总结句（"这些天他一直守约""她想了很久""她决定重选""早已成为她的一部分"）？有则改写成可见动作。
- [ ] 每个核心选择是否具备五要素（前置顾虑/亲自可见行动/对方克制回应/即时结果/不依赖附录）？
- [ ] **删附录测试**：删掉附录与作者说明后，仅凭动作与对白，观众能否看懂谁认输/谁见证/谁选择/谁担代价/因果为何成立？
- [ ] 安静情绪集是否有内部变化链（非靠对视/停顿/旁白拖时长）？
- [ ] 真相阶梯未越级（漂亮画面/失态没提前坐实下一级真相）？能动性未被夺（保护≠控制、配角未替主角判断）？

#### 画面描写检查 ✅

- [ ] △描写是否遵循Show, Don't Tell？
- [ ] 画面描写是否匹配选定的视觉风格？
- [ ] 是否使用了视觉情绪对照表而非抽象情绪词？
- [ ] 环境描写是否服务于情绪表达？
- [ ] 爽点/高潮场景是否使用了精细画面拆分？

#### AI画面可行性检查 ✅

- [ ] 有无红灯画面（复杂多人同时运动、手指特写、文字特写等）？
- [ ] 黄灯画面是否已简化或拆分？
- [ ] 每个精细画面的节拍是否足够简单（单一动作、5秒可完成）？
- [ ] 精细画面的节拍之间衔接是否自然？

#### 台词检查 ✅（详见 台词引擎（一句一功能 / 信息去重 / 四技 / 压缩流程））

- [ ] 有无超过3行的长台词（未加气口/小动作）？
- [ ] 每句台词是否一句一功能、提供新信息或推进情绪？
- [ ] 同集内是否有同层面重复信息（应删到只说一次）？
- [ ] 不同角色说话风格有区分（强势/弱势定位正确）？
- [ ] 背景信息是否用了VO旁白而非对话？

#### 格式检查 ✅

- [ ] 场景头完整（内/外、地点、日/夜）？
- [ ] 出场人物列齐？
- [ ] 关键画面标注了景别？
- [ ] 字数符合本题材+付费模式区间（后悔流1000-1200/爽剧500-800/平台硬性以平台为准）？
- [ ] (漫剧)末尾有画面节拍统计？

#### 连贯性检查 ✅

- [ ] 角色行为符合设定？
- [ ] 角色视觉锚点（服装、配饰）前后一致？
- [ ] 与前面已写的集数无矛盾？
- [ ] 时间线通顺？

#### 镜头密度估算

每集完成后统计：
- 总画面节拍数：XX个
- 其中精细画面节拍：XX个
- 常规画面节拍：XX个
- 预估视频总时长：约X分X秒（按每节拍5秒估算，精细画面按标注时长估算）

此数据帮助评估制作工作量和排期。

### 批量撰写建议

- 每5集做一次小回顾：角色弧线是否推进、视觉锚点是否一致
- 每10集做一次节奏校准：情绪曲线是否符合全剧规划
- 付费卡点前后3集特别精心
- 按任务规模选择内部批次；完成用户指定集数，只有明确要求逐批审批时才等待。

## 分场正文格式

优先沿用项目指定格式；无指定时使用下面的简洁模板。每场标题后第一条非空内容写人物行，列出当场出镜、发声及功能角色；电话和画外音注明方式，只被提到的人不列。

```text
剧名：《项目名》
第X集

X-1 日 内 修表铺
人物：林舟、顾岚

△ 林舟把修好的怀表推到柜台边。顾岚没有接。
林舟（试探）：分针不再慢了。
顾岚：我今天来，是取回钥匙。
△ 林舟握着钥匙，松开手，放到怀表旁。

【闪回】
X-2 夜 内 修表铺
人物：林舟、顾岚
△ 顾岚把钥匙交到林舟手中。
顾岚：明早替我开门。
【闪回结束】

X-3 日 内 修表铺
人物：林舟、顾岚
△ 顾岚拿走钥匙。怀表仍留在柜台上。
```

此短例是公开版新写的格式示例，不来自真实项目。

- 动作前使用项目统一的▲或△，避免同稿混用。场次含集数、场次、时间、内外、地点。
- 人物名后可加必要情绪或可表演动作。短句服务节奏，不强设25字上限；连续完整发言不要逐句重复人物名。
- VO、OS、闪回、闪回结束、跨场电话各自标明。闪回也要有场次和人物行。
- 主体身份字幕仅在叙事需要、且不越过知情边界时使用；不要为了格式而提前揭密。
- 集尾以当集真正发生的悬念、选择、危机或情绪变化结束，不额外用下集预告泄露下一集。
- 真人正文写清可拍动作与对白；AI或漫剧需要时附精细画面节拍。每节拍写一个明确动作与结束状态，时长依据制作要求。
- 只有交付要求包含制作估算时才附节拍统计；统计是估算依据，不是实际生成时长或算力消耗。

<a id="rule-6"></a>

## 钩子与付费卡点设计 (Hooks & Paywalls)

### 一、 黄金 3 秒法则与精品化开场
在精品短剧时代，可用“尽早给出吸引点”作为开篇目标，**3秒**是节奏示意而非普适统计。开场不仅要有冲突，更要通过“高概念”或“极致视觉”瞬间抓住眼球。

#### 1. 开场绝对禁忌 (Taboos)
- ❌ **拒绝低效叙事**：不要用旁白交代背景（"三年前，在一个小城市……"）。
- ❌ **拒绝情绪空白**：不要用慢节奏的环境空镜或角色独自走路/发呆的画面。
- ❌ **拒绝平淡开局**：不要用无意义的对话铺垫关系（"你是我姐夫的表弟？"）。

#### 2. 精品剧开场公式
> **高概念奇观（吸睛） → 核心危机引爆（共鸣） → 身份/关系降维打击（爽感）**
在第一个场次的前 3 行内，必须让观众感受到"这里有颠覆认知的事情要发生"。

---

### 二、 高概念开篇模板 (High-Concept Templates)
摒弃老套的“丈母娘扇巴掌”，引入具有更强视觉张力与设定新意的高级模板：

#### 模板 1：极致反差型 (取代传统打脸)
利用极具视觉冲击力的身份错位开场，不仅打脸，还要打出“奇观”。
> **示例指令**：
> △ （特写）一把带着全息投影的激光剑抵在主角的清洁工制服上。
> 反派：（嘲笑）低贱的基因，也配碰核心代码？
> △ （特写）主角缓缓抬眼，原本黑色的瞳孔瞬间重组为金色的数字矩阵。

#### 模板 2：高维降临型 (升级版身份反转)
开局主角处于绝对劣势，但反转的力度要达到“摧毁现有世界观”的级别。
> **示例指令**：
> △ （全景）暴雨中，主角被按在泥水里被迫签下卖身契。
> △ （远景转全景）云层突然撕裂，三艘遮天蔽日的星际战舰悬停在城市上空。
> 广播：（机械音响彻全球）检测到最高指挥官生命体征受损，正在锁定目标。

#### 模板 3：生死倒计时 (极端困境)
开场就是绝境，主角面对不可能完成的任务或生死抉择。增加时间限制，拉满肾上腺素。
> **示例指令**：
> △ （特写）定时炸弹倒计时显示：00:03。
> △ （近景）主角怀里抱着啼哭的婴儿，面前是深不见底的万丈悬崖。

#### 模板 4：结果前置/悬疑倒叙
先展示一个极度震撼、充满违和感的结局画面，再回溯"这一切是怎么发生的"。
> **示例指令**：
> △ （全景）昔日高高在上的财阀家族，此刻全部被锁在玻璃展示柜里。
> △ （中景）曾经被他们踩在脚底的男主，正优雅地端着红酒杯，像欣赏藏品一样看着他们。

#### 模板 5：规则重置/重生起始
主角死亡或遭遇极端事件后，突然回到过去或进入新规则世界。
> **示例指令**：
> △ （特写）主角的心脏被利刃贯穿，血液飞溅。
> △ （特写）画面瞬间倒转，时钟指针疯狂逆时针旋转。主角猛地在考场上惊醒，黑板上写着：距离末世降临还有 10 分钟。

---

### 三、 爆款付费卡点设计 (Paywall Mechanics)
付费卡点是免费内容与付费内容的分界线，是观众情绪和好奇心被推到极致的节点。在精品剧中，卡点必须具有“不可替代性”。

#### 1. 工业级卡点位置
| 剧集规模 | 建议付费集数 | 卡点位置特征 |
| :--- | :--- | :--- |
| **标准男频/爽剧** (60集) | 第 8-12 集 | 主角底牌即将掀开 / 第一次降维打击的最后一秒。 |
| **女频/甜宠剧** (50集) | 第 6-10 集 | 极限拉扯的顶点（如：男女主第一次假戏真做 / 被迫分离）。 |
| **强悬疑/无限流** (50集) | 第 8-10 集 | 规则被打破 / 最信任的人露出诡异微笑。 |

#### 2. 卡点设计三原则 (The 3 Rules of Paywall)
- **悬而未决**：最关键的信息（如：那一剑有没有刺中？那份DNA报告写了什么？）差一步就要揭晓——但截然而止。
- **情绪绝顶**：愤怒、震撼、心疼或好奇被推到生理极限。
- **不可回头**：故事已经走到了一个"不看下一集就睡不着"的位置。

---

### 四、 单集微钩子矩阵 (Micro-Hooks)
每集结尾的最后 10 秒都是"钩子"——让观众自动点开下一集的强制装置。

#### 1. 钩子类型与效果
| 钩子类型 | 心理效用 | 视觉化示例 |
| :--- | :--- | :--- |
| **悬念钩** | "接下来会怎样？" | 门被猛地推开，主角看到了一个本该在十年前死去的人。 |
| **反转钩** | "居然是这样！" | 反派撕下伪装的面具，露出的竟然是主角父亲的脸。 |
| **情绪钩** | "太气了/太燃了！" | 反派得意大笑，但身后的主角已经拔出了那把尘封的神剑。 |
| **信息钩** | "原来还有隐情！" | 泛黄的日记本掉在地上，最后一页用血写着一个名字……（黑屏）。 |
| **危机钩** | "他能活下来吗？" | 刹车失灵，大货车迎面撞来，车灯占据了整个屏幕——（黑屏）。 |

#### 2. 钩子执行铁律
- **密度强制**：每集结尾优先突出一个最强钩子，大结局按收束需要处理。
- **强度分级**：关键集数（如付费卡点前后 5 集）的结尾钩子强度必须拉满，涉及生死或核心秘密。
- **无缝咬合**：下一集的前 30 秒内 **必须** 直接回应上一集的结尾钩子，严禁通过拖沓过渡来消耗观众耐心。

<a id="rule-7"></a>

## AI仿真人剧写作法（区别于漫剧 / 真人剧）

> 本文件解决最核心的混淆：**真人短剧、AI仿真人剧、漫剧是三种不同的生产模式**，剧本写法不同。
> 在 Stage 1 定标时先从任务信息确定本项目是哪一种，再挂载对应规则。

---

### 0. 三种生产模式速辨（先选模式，再写剧本）

| 维度 | 真人短剧 | AI仿真人剧 | 漫剧（2D/AI漫画剧） |
|---|---|---|---|
| 成片形态 | 真人演员实拍 | AI生成"拟真人"影像 | 2D/CG动画 |
| 剧本侧重 | 重台词、重情感细节、重微表情；轻场面、少转场 | 重情绪、重大场面、重视觉标签；表演靠剧情张力带，不靠微表情 | 重脑洞奇观、重特效 |
| 易做题材 | 都市、年代、民国、古装（易拍、下沉世情） | 真人难拍的题材也行：都市、古代、末世、玄幻、脑洞无限流 | 修仙、玄幻、神兽、系统流 |
| 谁来把控画面 | 导演 | **可能没有导演**（生成师多为动画/CG/剪辑转行，不懂戏） | 分镜师/AI |

> 同一故事可适配不同生产方式。区别主要在详写程度、表演和画面交接，而不是题材名。

---

### 1. AI仿真人的四项制作适配

#### 适配1：按实际表演效果调整节奏
当样片显示表演不足时，过长停留可能暴露问题。用**快速情节推进 + 大起大落**转移注意力。
- 慎用"沉默两秒"等留白——改用快速镜头切换、特写、环境音、或更激烈的台词动作填补。

#### 适配2：让情绪有明确可见的表达
如当前工具难表现细腻复杂情感，可让喜怒哀乐要**鲜明、转换直接**。
- 用**更夸张的剧情冲突 + 更极端的台词**带动情绪，让观众忽略表演细腻度。
- 人设宁可极端鲜明，但参考真实（见 “情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账）”章节 的"又当又立"原则）。

#### 适配3：制作交接需要时写得更细（关键交接要求）
当制作人员需要更多叙事说明时，可能依赖明确的画面说明。写不细 → 理解偏差 → 成片崩。
- 除场景外，**详细刻画面部表情、细微动作、语气停顿**。
  - 范例："他愣了一下，眼中闪过一丝疑惑，随后转为冰冷的愤怒，缓缓开口道……"
- 每次切换场景必须写清楚（对仿真人尤其重要，避免生成错画面）：
  ```
  【场景A】男主在办公室打电话……
  【切到场景B】女主在家中接电话……
  【切回场景A】男主愤怒……
  ```
- 剪辑/配乐指令可直接写进正文：闪回回音拆"前半句VO回音、后半句带场景"；情绪燃点标注"（音乐可以燃一点）"。

#### 法则4：视觉标签防同质化（写进人物小传）
AI生成易撞脸、形象漂移。给每个角色一个**醒目、唯一的视觉锚点**，写进人物小传：
- 女主永远簪一朵白玉兰；只有狐妖女主头上有狐耳；大哥寸头、二哥斜刘海。
- 角色名后直接括注服化造型：`李初微（抹胸吊带）`、`刘小姐（胖丑，脸上有大胎记斑点）`。
- 关键场景可插入氛围参考图（开局/重要卡点），不必全文贴。

---

### 2. "看到，而不是做到"——画面感写法

为观众视角写，而非小说里主角视角：

| ❌ 小说式（做到） | ✅ 剧本式（看到） |
|---|---|
| 主角推开门走进来了 | 门推开，主角走两步进门 |
| 女主哭得非常伤心 | 女主闭眼，两行泪落下 |
| 他很生气 | 他攥紧拳头，指节发白，杯子在掌心捏到变形 |

复合/转折表情要写明：`（哭着笑）`、`（边崩溃边流泪控诉）`、`（笑容僵住）`——这是仿真人表演的关键指令。

用精确数字量化处境与目标，比形容词更扎心：月薪700、补贴家里600、凑1.5万彩礼、拆迁款100万分70万+30万。

---

### 3. 平台是否有导演把控（决定写多细 / 字数）

投稿前必问编辑："你们平台有没有导演把控？需要我加很多画面描述吗？"

- **有导演把控**：你只写剧情，导演做画面润色和提示词；正文写法接近真人剧。
- **无导演把控**：你要把灯光、场景形容词写到位方便AI直接生成；字数要求更高（常 800-1000）。

> 字数不是越多越好，是"够生成师无歧义执行"为准。详见 “分集撰写要求与自检清单（通用，按生产模式调整）”章节 的"题材+付费模式驱动字数"。

---

### 4. 制作交接 checklist（剧本 → 生成师 / 视觉导演）

- [ ] 每个主要角色有唯一视觉标签，且写进人物小传
- [ ] 每次转场写清【场景X】，跨场电话/对话标了"切到/切回"
- [ ] 关键情绪点写了复合表情与细微动作（非抽象情感词）
- [ ] 闪回/闪入标注清楚（`闪入`=新画面需重新生成；`闪回第X集…闪回结束`=剪辑复用，见 “分场正文格式”章节）
- [ ] 红灯AI画面已规避或拆解（见 “AI画面可行性意识”章节）
- [ ] 大场面/特效场景标注了参考图或氛围描述

---

### 5. 与本skill其它文件的关系
- 格式符号（▲/OS/VO/闪入/闪回）→ “分场正文格式”章节
- AI能不能生成某个画面 → “AI画面可行性意识”章节
- 情绪外放怎么落地 → “情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账）”章节
- 台词怎么写有力 → “台词引擎（一句一功能 / 信息去重 / 四技 / 压缩流程）”章节

<a id="rule-8"></a>

## AI画面可行性意识

### 概述

本模块为编剧在「写剧本阶段」提供AI视频生成能力边界的意识指导。目标是从源头减少不可执行的镜头描述，提升下游制作效率。

注意：这里是编剧层面的"意识"指导，不是精确的技术规范。精确的平台规范（如某模型的提示词长度、@引用系统、运镜写法等）由下游的AI视频分镜师团队Agent负责。


### 绿灯画面（优先使用）

下列是历史制作中较易尝试的画面类型，仍需用当前工具验证：

| 画面类型 | 说明 | 示例 |
|----------|------|------|
| 静态人物特写 | 人物面部表情、情绪变化 | "瞳孔收缩，嘴角微微上扬" |
| 简单单人动作 | 走、跑、转身、抬手、站起、坐下 | "缓缓站起身，拂去肩上的灰尘" |
| 环境氛围渲染 | 天气、光影、自然景观 | "晨雾未散，远山若隐若现" |
| 光影变化 | 从暗到亮、逆光、光束 | "阳光从云层间倾泻而下" |
| 特效/能量表现 | 发光、气流、粒子效果 | "金色灵力从掌心涌出" |
| 物件特写 | 信件、武器、饰品等 | "古剑的剑身上浮现出神秘铭文" |
| 表情渐变 | 情绪的缓慢变化 | "从震惊到释然，嘴角逐渐放松" |
| 风/水/火等自然元素 | 自然力的视觉表现 | "火焰在掌中跳动，照亮了他的脸" |

### 黄灯画面（可以写，但要简化）

下列画面可作为试做重点，必要时简化描述或拆分：

| 画面类型 | 风险点 | 建议处理 |
|----------|--------|----------|
| 两人互动 | 两人的动作容易不协调 | 每个画面聚焦一个人，切镜头表现互动 |
| 中等复杂打斗 | 动作连贯性难保证 | 拆成多个5秒短镜头，每段只做一个动作 |
| 动物/生物 | 形态可能不稳定 | 减少运动幅度，多用静态或缓慢动作 |
| 群体场景（3-5人） | 人物容易变形或融合 | 用全景/远景，不要求每个人的细节 |
| 快速运动 | 容易产生拖影或变形 | 用暗示代替直接展示，或拆成起始+结果 |

### 高风险画面（测试后决定是否改写）

下列画面在历史实践中常见失败；先测试当前工具，必要时使用等效替代方案：

| 红灯画面 | 为什么做不好 | 替代方案 |
|----------|-------------|----------|
| 复杂多人同时运动 | 模型难以同时控制多个运动主体 | 分切多个单人/双人镜头交叉剪辑 |
| 精确手指动作 | 精细动作可能不稳定 | 用中景或远景避开手部特写，或改为握拳/挥手等大动作 |
| 文字特写（信件、书本） | 字形与排版可能不准确，可用后期叠字 | 用VO旁白读出内容，画面只拍"拿着信的手"而非信上的字 |
| 远距离连续追逐 | 长时间运动场景一致性差 | 拆成多段短镜头：追→跑→追上→对峙 |
| 空中连续翻转 | 复杂空间运动可能需要拆镜 | "身影从高处一跃而下"→切镜头→"稳稳站在地面" |
| 精确的唇形对口型 | 中文对口型效果不稳定 | 重要台词用近景（不是特写），或配合VO处理 |
| 镜子中的倒影 | 镜像一致性差 | 避免镜子剧情，改用水面模糊倒影 |
| 同一角色不同年龄 | 跨年龄一致性差 | 用不同镜头分别展示，靠旁白或字幕交代是同一人 |

### 替代写法速查

#### 场景一：主角从悬崖跳下精准落马

❌ 原始写法：主角从悬崖跳下，在空中连续翻转三圈后精准落在马背上

✅ 替代写法（拆成3个画面节拍）：
- 节拍1：主角站在悬崖边，衣袂飘动，向下纵身一跃
- 节拍2：俯拍，人影急速下坠，风声呼啸
- 节拍3：马背上，主角已经稳稳坐好，拉住缰绳，马嘶鸣

#### 场景二：多人围攻主角的混战

❌ 原始写法：十个黑衣人同时向主角冲来，主角一一闪避并反击

✅ 替代写法（分切表现）：
- 节拍1：（全景）十个黑影从四面八方逼近主角
- 节拍2：（近景）第一人挥刀砍来，主角侧身闪过，一掌拍在对方胸口
- 节拍3：（中景）又两人从背后偷袭，主角脚下一转，气浪将两人震开
- 节拍4：（全景）尘烟散去，十人全部倒地，主角站在中央，衣角微动

#### 场景三：角色读信然后大怒

❌ 原始写法：主角拿起信件，看到上面写着"你的父亲已经死了"，勃然大怒

✅ 替代写法：
- △（近景）主角拆开信封，目光扫过信纸。
- VO：（低沉旁白）"你的父亲已经死了。"
- △（特写）主角的手开始颤抖，信纸被捏出褶皱。
- △ 信纸从手中滑落飘向地面（慢动作）。

### 当前工具校准

使用方需依据实际模型版本、参考图、单次时长、角色一致性与音画同步能力做少量试镜。无法直接生成的文字可后期叠加；复杂动作可拆为起因、过程、结果和反应镜。这里不保存某厂商的当前参数、价格或成功率。

### 编剧自检提示

写完每个△描写后，快速过一遍这三个问题：
1. 这个画面是一个简单动作还是复杂连续动作？（复杂→拆分）
2. 画面中有几个运动主体？（超过2个→简化或分切）
3. 有没有手指特写或文字特写？（有→改写）

养成这个习惯后，AI可行性就会自然融入写作，不需要额外检查。

## 漫剧画面写作规范

### 核心原则：Show, Don't Tell

漫剧没有真人演员，画面完全靠AI生成。剧本的△描写就是"导演的眼睛"——写什么，观众就看到什么。

**铁律**：不要告诉观众角色在想什么或感受什么，要展示能让观众自己感受到的画面。

| ❌ 告诉（短剧写法） | ✅ 展示（漫剧写法） |
|---------------------|---------------------|
| 他很愤怒 | 指节捏得发白，额角青筋暴起，桌面被拍出裂纹 |
| 她很伤心 | 雨水顺着脸颊滑落，分不清是泪还是雨，手中的信纸被打湿模糊 |
| 他很紧张 | 喉结上下滚动，额头渗出细密的汗珠，手指在袖中微微发抖 |
| 气氛很压抑 | 阴云压顶，树叶纹丝不动，空气仿佛凝固，远处传来乌鸦的叫声 |
| 他实力很强 | 仅仅抬手，对面三人已经被气浪掀飞，撞穿了身后的石墙 |

### 弧线层 Show-Don't-Tell（关键补充：演出"改变如何发生"，不要总结"改变已完成"）

上面的对照表解决**情绪层**（把"他很愤怒"画成动作）。但更隐蔽、更常翻车的是**弧线/选择层**——用一句总结句直接宣布人物已经改变、已经守约、已经选择，观众却**没有亲眼看到变化发生**。单集自检常常"通过"，连读却空。

**病症（禁用这类"作者声称已发生"的总结句）**：

| ❌ 宣布已完成（禁用） | ✅ 演出正在发生 |
|---|---|
| "这些天，他一直守约" | 让对方引用**一个具体兑现行为**："那天在门口你只站着，她喊停你就停了" |
| "她想了很久" / "她做了决定" | 她**拿起听筒，自己拨了号**；动作即决定 |
| "这几个星期，他一条边界都没破" | 她到场时他**坐在门边等、没用连接、没找进来**（当下可见的守约） |
| "碎片早已成为她的一部分" | 她**当场念出"我让它留下"**，胸口光随之转化（她选择触发的可见结果） |
| "她决定重新选择他" | 她**走过去、坐下、说出新条件、伸手**——选择由可见动作完成 |

**每个结局/重建核心选择，必须同时具备五要素**：

1. 选择前的**具体阻力或顾虑**（"我大可以转身就走"）；
2. 当事人**亲自做出的可见行动或明确请求**；
3. 另一方**如何克制、等待或回应**；
4. 选择产生的**即时结果**；
5. 结果**不依赖附录或作者说明**解释。

**删附录测试（强制交稿门）**：删掉全部附录、特效说明与作者注后，普通观众能否仅凭**动作与对白**看懂"谁认输、谁见证、谁选择、谁承担代价、因果为何成立"？看不懂，就继续改写。**正文不是证明 Beat 已完成，而是让观众亲眼看见 Beat 如何发生。**

> 此规则对三种生产模式都适用（不止漫剧）。配套：“一次通过协议（交稿前自查 SOP，降低返工轮数）”章节 第三/六节、“真相阶梯、能动性与语义不混淆（继承与伦理规则库）”章节 第三节能动性铁律。

### 视觉情绪对照表

写漫剧剧本时，用这张表将抽象情绪映射为具体画面：

#### 愤怒系

| 程度 | 画面表现 |
|------|----------|
| 隐忍 | 握拳，指甲掐入掌心，手背青筋浮起 |
| 爆发前兆 | 瞳孔收缩，呼吸急促可见胸腔起伏，周围空气开始扭曲 |
| 全面爆发 | 怒吼，气浪以身体为中心向外扩散，地面龟裂，碎石漂浮 |

#### 震惊系

| 程度 | 画面表现 |
|------|----------|
| 微惊 | 瞳孔微张，手中的动作停顿一瞬 |
| 震惊 | 眼睛圆睁，手中的物品脱手掉落（慢动作），嘴唇微张 |
| 极致震撼 | 双膝发软后退一步，画面出现短暂的失焦然后重新对焦 |

#### 悲伤系

| 程度 | 画面表现 |
|------|----------|
| 隐痛 | 低下头，刘海遮住眼睛，肩膀微微塌下 |
| 心碎 | 泪水无声滑落，手指无力地松开某个重要物品 |
| 绝望 | 跪倒在地，双手撑地，雨水/雪花落满肩头，周围色调变灰 |

#### 觉醒/爆发系（漫剧高频场景）

| 程度 | 画面表现 |
|------|----------|
| 初始觉醒 | 瞳孔变色（金/红/紫），皮肤下浮现发光纹路 |
| 力量涌出 | 头发飘起，衣袂猎猎，脚下地面出现裂纹，光芒从体内涌出 |
| 完全释放 | 身后出现虚影（龙/凤/法阵），能量化为实质向四周扩散 |

#### 霸气/碾压系

| 程度 | 画面表现 |
|------|----------|
| 淡定碾压 | 表情不变，仅用一根手指挡住对方全力一击 |
| 气势压制 | 眼神扫过，目光所及之处的人不由自主后退，空气肉眼可见地扭曲 |
| 绝对碾压 | 随手一挥，对手的武器碎裂，人像断线风筝般飞出画面 |

### 环境即情绪

漫剧可以用环境来强化情绪表达，这是真人短剧做不到或成本极高的优势：

| 情绪 | 环境表现 |
|------|----------|
| 压抑/危机 | 阴云密布、色调偏冷偏暗、风沙、枯枝 |
| 逆袭/爆发 | 金光万丈、云开雾散、色调从灰暗骤变为明亮 |
| 甜蜜/温馨 | 樱花/花瓣飘落、暖色阳光、柔焦背景 |
| 恐惧/悬疑 | 浓雾、影子拉长、光源摇曳不定、色调偏绿偏青 |
| 孤独/寂寞 | 空旷场景、主角渺小的身影、冷色月光 |
| 终极对决 | 天地变色、雷电交加、地面崩裂、两股能量对冲 |

写法示例：
- ❌ "气氛变得紧张起来"
- ✅ "天边的乌云压低，远处传来沉闷的雷声。风骤然停了，树叶凝固在半空"

### 画面颗粒度拆分

#### 什么时候需要精细拆分

同样一段剧情，拆成多个短画面比写成一个长画面更利于AI生成。但不是所有地方都需要拆——只在关键场景精细化。

**必须精细拆分的场景**：
- 爽点高潮（身份揭露、打脸、逆袭、觉醒爆发）——这些是全剧的"钱景"
- 复杂动作序列（打斗、追逐、特效爆发）——AI最容易翻车的地方
- 情绪重大转折（从隐忍到爆发、从绝望到希望）——需要渐进表现

**不需要拆分的场景**：
- 普通对话和过渡
- 简单的走路、坐下、环顾等日常动作
- 环境交代

#### 精细画面的写法


```
△ 【精细画面】灵根觉醒

△ （近景）林风双膝跪地，双手撑着地面，额头汗珠滚落。
  手背上的青筋突起，指缝间的泥土被捏碎。

---

△ （特写）林风的手背——皮肤下突然浮现一道金色纹路，
  像闪电一样从手腕蔓延到指尖，微光脉动。

---

△ （中景）金色光芒从林风全身涌出，头发被气流扬起，
  衣袂猎猎飘动。他缓缓站起，双眼已变成纯金色。

---

△ （全景）光芒化为冲击波向四周扩散，地面的落叶和碎石
  被气浪卷飞，围攻的黑衣人纷纷后退踉跄。
```

#### 普通画面的写法

不加精细标记，按正常段落书写：

```
△ （中景）林风推开木门走进客栈，环顾四周，
  找了个角落的位置坐下，对小二招了招手。
```

#### 节拍的设计原则

- 每个节拍只描述一个简单动作或一个画面状态变化
- 每个节拍的内容在5秒视频时长内可以完成
- 如果一个节拍的动作太复杂（AI可能做不好），就继续拆
- 节拍之间的衔接要自然——上一个节拍的结束状态就是下一个节拍的起始状态

### 漫剧专属标记

在原有标记基础上（△、【】、♪、☎），新增以下漫剧专属标记：

| 标记 | 含义 | 示例 |
|------|------|------|
| 🎨 | 视觉风格提示 | 🎨 水墨风留白构图 |
| ⚡ | 特效描述 | ⚡ 灵根觉醒金光涌出 |
| OS | 角色内心独白 | OS：（林风内心）这一次，我不会再退让 |
| VO | 画外音/旁白 | VO：（低沉旁白）三千年前，天地初开…… |

这些标记是辅助信息，帮助阅读者快速识别场景类型，不影响剧本的阅读流畅度。

### 景别使用原则（漫剧特化）

| 景别 | 漫剧中的适用场景 | 使用频率 |
|------|-------------------|----------|
| 全景/远景 | 世界观展示、大场面、战斗全貌、环境渲染 | 每集3-5次 |
| 中景 | 对话、互动、常规叙事 | 最高频 |
| 近景 | 情感表达、重要对话、反应 | 高频 |
| 特写 | 情绪爆发、关键物件、表情细节、觉醒/变化 | 爽点必用 |

漫剧特别注意：
- 觉醒/爆发类场景，推荐「特写→中景→全景」的景别递进——先看细节变化，再看整体效果
- 打脸类场景，推荐「近景（反派嚣张）→特写（主角表情）→全景（碾压画面）」
- 不要连续多个同景别画面——景别变化本身就是节奏

## 漫剧视觉风格选择系统

### 概述

视觉风格的选择直接影响剧本的画面描写方式。选定风格后，全剧所有△描写都要匹配该风格的美学特征。此选择结果也会传递给下游的AI视频分镜师团队Agent。

### 风格选项

#### 1. 3D CG渲染风格

**适配题材**：修仙觉醒、玄幻逆袭、末世重生、战神归来、神兽进化

**美学特征**：
- 精细的材质质感（皮肤毛孔、衣物纤维、金属光泽）
- 电影级光影层次（体积光、全局光照、景深虚化）
- 空间纵深感强（前景/中景/背景层次分明）
- 动作流畅度高，适合打斗和特效场景

**对剧本写法的影响**：
- △描写注重材质和质感词汇："金属铠甲反射着冷光""丝绸长袍随风飘动"
- 光影描写要具体："逆光勾勒出轮廓""侧光在脸上投下硬朗阴影"
- 特效描写可以大胆："金色灵力化为实质的龙形""空间裂缝中涌出暗紫色能量"
- 适合大量使用特写和近景，展示材质细节

**品质锚定词**（供下游Agent使用）：UnrealEngine5渲染、电影级柔光照明、精细皮肤材质、发丝细节清晰

#### 2. 2D赛璐璃风格

**适配题材**：甜宠、校园、轻奇幻、搞笑日常

**美学特征**：
- 清晰的轮廓线和色块填充
- 色彩明亮饱和，对比度高
- 表情夸张生动，肢体语言放大
- 适合Q版变形和夸张表情插入

**对剧本写法的影响**：
- △描写可以包含夸张的表情描写："眼睛瞪成铜铃大""嘴角咧到耳朵根"
- 可以标注Q版/夸张化处理："△（Q版）主角气得头顶冒烟"
- 色彩描写要鲜明："粉色的樱花花瓣铺满整个画面""金色的光芒像烟花一样绽放"
- 动作描写偏动态夸张："一个箭步冲到面前""滑稽地撞到门框上"

**品质锚定词**：日系赛璐璃动画风格、鲜明色彩、流畅线条、动态构图

#### 3. 水墨国风

**适配题材**：古装仙侠、武侠、历史传奇

**美学特征**：
- 水墨晕染效果，边缘虚化
- 色彩淡雅（墨色、赭石、靛蓝、留白）
- 大量留白构图，意境感强
- 远景和全景使用频率高
- 动态效果偏写意而非写实

**对剧本写法的影响**：
- △描写注重意境和留白："远山如墨，云雾间隐约可见飞鸟""剑光划过，只留下一道墨色残影"
- 多用远景和全景建立氛围，少用极端特写
- 动作描写偏写意："身形如柳絮般飘起""剑招如行云流水"
- 环境描写要有诗意："月光洒在湖面，碎成满池银光"
- 避免过于具体的材质描写（与水墨的朦胧感矛盾）

**品质锚定词**：中国水墨画风格、留白构图、淡雅色调、写意动态

#### 4. 厚涂写实风格

**适配题材**：都市悬疑、暗黑复仇、心理惊悚

**美学特征**：
- 笔触感明显，色彩厚重
- 光影对比强烈，明暗分明
- 质感偏油画感，色调偏暗沉
- 适合表现人物内心的复杂情绪

**对剧本写法的影响**：
- △描写注重光影细节："街灯在湿漉漉的地面上投下变形的影子""烟雾缭绕中只能看到一双冷峻的眼"
- 色调描写偏暗沉："阴沉的灰色天空""暖黄的台灯光圈外是浓重的黑暗"
- 大量使用特写展示表情细节和情绪变化
- 环境描写要有压迫感或氛围感

**品质锚定词**：厚涂写实风格、强对比光影、油画质感、暗色调

#### 5. 美漫/赛博朋克风格

**适配题材**：出海科幻、超能力、赛博朋克、暗黑英雄

**美学特征**：
- 高饱和度对比色（霓虹粉、电光蓝、亮绿）
- 动态构图，倾斜角度，速度线
- 强烈的视觉冲击力
- 适合能量爆发和高速运动

**对剧本写法的影响**：
- △描写注重速度感和冲击力："拳风带起的气浪掀翻了桌椅""能量光束撕裂了夜空"
- 色彩描写要大胆："霓虹灯光在雨水中碎成彩虹""全息投影的蓝色光芒照亮了他的脸"
- 构图可以非常规："俯拍，主角站在摩天大楼边缘""仰拍，巨大的机甲投下阴影"
- 适合快节奏剪辑和硬切

**品质锚定词**：美漫风格、高饱和霓虹色彩、动态构图、赛博朋克光效

#### 6. 真人写实风格（仿真人）

**适配题材**：都市情感、家庭伦理、职场、霸总

**美学特征**：
- 尽可能接近真人拍摄的效果
- 自然光影，写实比例
- 表情和肢体语言追求自然
- 场景和服装追求生活质感

**对剧本写法的影响**：
- △描写最接近真人短剧的写法，但要比真人短剧更具体
- 避免过于夸张的特效描写（真人写实风格跑不出夸张特效）
- 注重生活化细节："咖啡杯冒出的白色热气""指尖无意识地转动着戒指"
- 表情描写要微妙而非夸张："嘴角微不可察地抽搐了一下""眼底闪过一丝不易察觉的寒意"

**品质锚定词**：写实CG风格、自然光照、真实皮肤质感、生活化场景

### 风格选择后的操作

用户选定风格后：
1. 将风格名称和美学特征写入 `创作方案.md` 的「视觉风格定义」板块
2. 后续所有分集剧本的△描写自动匹配该风格的写法指导
3. 此风格定义可直接传递给AI视频分镜师团队Agent作为 project-config

<a id="rule-11"></a>

## 真相阶梯、能动性与语义不混淆（继承与伦理规则库）

> 适用全部生产模式。本文件管三类**最容易被普通审稿漏掉、却会改变观众对因果理解**的问题：分集信息边界（真相阶梯）、主角能动性、语义混淆。配套 “一次通过协议（交稿前自查 SOP，降低返工轮数）”章节（敌对审读）与 “漫剧画面写作规范”章节（show-don't-tell）。

### 一、底稿与锁定项

先读取项目指明的权威底稿、最新已确认变更及锁定项。作者明确批准的修改在其范围内有效；底稿与指定文件有未决实质冲突时询问，只暂停受影响写入。原著在忠实改编任务中可能是事实来源，不能一概降为灵感；历史废弃设定不得自行恢复。

参考剧提供方法与执行语法，不能覆盖本项目的剧情事实与用户授权范围。

### 二、真相阶梯（分集信息边界，不得越级）

多段式揭秘必须**逐级推进**，每一集只解锁本级信息：

- **典型三阶**：① 只见异常（"他不是普通人"）→ ② 只得动机（"他在找某样东西"）→ ③ 才完整真相（赌约/责任/身份全交底）。
- 每集任务卡显式写两栏：**允许透露 / 禁止透露**。
- **最易犯的越级**：让一个漂亮画面或角色失态**提前坐实下一级真相**（例：角色对一幅画失态，只能证明"他认得、在隐瞒"，不能让观众/主角在本集确认"画中人就是他"）。
- 物证层与点破层分离：可出现"同一意象画了二十年"（物证/时长），但**不得由任何角色把它与"他为某物定向寻找你"挂钩明示**（点破留给指定集）。
- 配角揭露与主角认知分级：配角可质问，但**串联线索、形成怀疑/判断的主体必须是主角本人**。

### 三、能动性铁律（保护≠控制，帮助≠恩赐）

1. 强者出手只**终止威胁**，不替对方决定、不替对方赢；**每次越界必有可见关系代价**（权限收紧/信任裂痕），不能用一句道歉抹平。
2. 主角每次接受帮助，都必须保留一个**由她本人完成**的关键行动。
3. 配角（朋友/长辈）**不得替主角完成判断、反击或胜利**；可以提醒、质问、提供线索，但决定权归主角。
4. 关键的**重选、邀请、通知、允许、归属决定**必须由当事人**亲口提出＋亲自行动**呈现，不能用"她决定了""她想了很久"带过。
5. 受害/被救者的解放（如离开施害者）**必须始终是其本人的选择**，他人只响应其提出的需要。
6. 现实程序要有**现实入口**：警察/制度介入不能凭空出现，需可见的报警/报备/证词链。

### 四、语义不混淆（台词与画面须肉眼可分）

| 不可混淆 | 正确口径 |
|---|---|
| 个人信条 vs 客观规则 | 主观信念只由持有者本人说出；规则裁断者只讲客观规则、**不确认信条真假**；结局可证伪信条而非推翻规则 |
| 一果多因不混 | "撤回某条件→某后果停止"与"某物仍在/归属未变"是两件事，分开表达 |
| 恢复能力 vs 学会感受 | 主题反转若是"学会作为人去感受"，就**不能写成取回某物的新机制**，也不让角色自信解释成新规则——只落主题判断 |
| 保护 vs 控制 | 见第三节铁律 1 |
| 帮助 vs 恩赐/包养 | 接受帮助 ≠ 交出选择权 |

### 五、调度与场所逻辑自洽

- 人物不能"提前在场"又被"邀请到场"；到场时点、停留位置（如"只站门口不进屋"）要与边界约定一致。
- 时间流逝用字幕＋蒙太奇明示（"X 周后"），跨集时间线硬要求（如重大事件需间隔数周）必须可见。
- 越界力量梯度严格按设定递增/克制，**勿因旧"强度递增"字面把后段写得强过前段**（克制本身可以是更强诱因下的零释放）。

## 一次通过协议（交稿前自查 SOP，降低返工轮数）

> 适用 AI仿真人 / 真人 / 漫剧 三种生产模式的**正文生成端**。目标：主笔在内部完成写作→敌对审读→修正后再交稿，不把明显可自查的问题留给下一轮审稿。
> 一句话原则：**不只检查"作者想表达什么"，交稿前必须检查"普通观众只看一遍会误读成什么"。**
> 配套：弧线层 show-don't-tell 见 “漫剧画面写作规范”章节；真相阶梯/能动性/语义见 “真相阶梯、能动性与语义不混淆（继承与伦理规则库）”章节。

### 一、写作前五格状态卡（动笔前内部确认，不必输出长报告）

1. **开场状态**：上一集最后发生了什么、人物此刻为什么在这里。
2. **知情边界**：每个角色已经知道什么、绝对不知道什么（接 “真相阶梯、能动性与语义不混淆（继承与伦理规则库）”章节 真相阶梯）。
3. **关系与权限**：当前允许靠近、帮助、触碰、决定到什么程度。
4. **连续性台账**：人物位置、住处、伤势、道具分别在哪里。
5. **本集终点**：本集必须发生的质变与唯一最强集尾钩子。

> 任一项无法从真源确认时，**先标记冲突、不得自行补设定**。

### 二、写作结构门（正式正文必须满足）

- 检查本集是否形成有效变化，按情节需要选用：局势 / 权力 / 关系 / 信息 / 选择。
- 关键行动后**至少出现一次**反击、拒绝、误读或即时后果（不能只完成信息宣读）。
- 主角**至少一次由简单可见行动落地的选择**（不是只靠一句宣言）。
- 钩子必须**由本集最后一次变化自然造成**，每集只保留一个最强钩子，黑场后无追加预告。
- 不以**新增人物/场域/大事件/世界规则/重复争吵/氛围停顿**虚增密度。
- **安静情绪集也必须有内部变化链**：用"提问逐层收窄→惯性答案被排除→拒绝表演式回答"这类递进，不靠对视、停顿、旁白拖时长。

### 三、交稿前敌对审读（假设自己是"易误解、只看一遍"的普通观众，逐场过）

1. **规则误读**：把"现在不能"写成"永远不能"？把"不能强取"写成"永远不能由她决定转移"？漂亮画面意外新增能力/历史/宇宙规则？提前确认了后续真相？
2. **能动性误读**：把主角争取到的权力写成对方"允许/给予/让给"？让保护、帮助或连接替主角做决定？让配角替主角完成判断、反击或胜利？
3. **控制与浪漫误读**：把疼痛/连接/力量/资源写成留住对方的工具？把越界行为浪漫化或轻轻带过？用心软消解上一集仍未付清的行为代价？
4. **连续性误读**：人物/道具/伤势/居所能否从上一集自然到达本集？同类道具观众能否区分？本集动作是否需靠附录/自检/审稿人脑补才成立？
5. **制作误读**：是否出现精细手指动作、连续复杂动作、群体同步动作、文字特写或难保持一致的奇观？能否拆成清楚的起因镜、结果镜与反应镜？

### 四、高风险词扫描（非禁用，但每次出现都要确认语义范围准确）

`永远`、`谁都`、`不能`、`取不走`、`逼`、`拽`、`拉回来`、`让给`、`允许`、`属于他`、`无法离开`、`注定`

> 这些词易制造"绝对规则""控制关系""能动性被夺"误读。尤其在多段揭秘里，涉"寻找/命运"的措辞勿用`注定`等提前坐实下一级真相。

### 五、跨集检查（批次完成后连续阅读）

读：上一集结尾 + 当前批次全部正文 + 下一集核心 Beat。只查四件事：

1. 每集是否承担**不同功能**并形成升级；
2. 情绪与关系是否出现**无因跳变**；
3. 真相、道具、地点、伤势是否**连续**；
4. 相邻集的场域、冲突、钩子是否**过度同构**（接 “节奏设计与三幕微结构”章节）。

### 六、提交格式（按本次交付要求选择）

1. **干净正文**文件（场景与台词；制作要求另需节拍统计或特效清单时再附）。
2. **简短落实表**：任务卡必须项如何兑现。
3. **敌对审读结果表**：只列①已自行修正的问题；②仍存在、需上报裁定的不确定项。

**禁止**：用长篇自检反复证明自己正确；正文后附大量历史说明；用"全部红线守住"代替实际检查；遇真源冲突自创解决方案（应标记上报）。

> **删附录测试（强制）**：删除全部附录与作者说明后，观众能否仅凭动作与对白看懂"谁认输、谁见证、谁选择、谁承担代价、因果为何成立"？看不懂就继续改写——详见 “漫剧画面写作规范”章节 弧线层 show-don't-tell。

### 七、审读与批次

主笔先自查，必要时按任务规模选择独立审读，不要求固定多Agent团队。审读只指出真正影响交付的问题，不凑轮次或数量。批次大小服务连续性与工作量；前一批有未决真源冲突时先解决依赖，但普通内部批次结束不构成等待用户的理由。

修改前保留可恢复版本，按授权范围修复问题，不顺手重写已通过内容。必要检查通过且无实质问题后交付。

## 冲突设计与爽点策略 (Conflict Design)

### 一、 工业级爽点底层算法
爽点 = **期待（极致压抑） × 反差（身份/实力错位） × 释放（视觉化碾压）**
*铁律：压得越低，弹得越高。所有没有压抑铺垫的装X，都是无效爽点。*

### 二、 核心爽点矩阵（出海/男频特化）
1. **身份碾压型**：隐藏极深的至高身份被物理证据当众揭穿（如：直升机群降落、全球黑卡掉落）。
2. **打脸复仇型**：反派叫嚣到最高潮时，主角以绝对力量一招制敌（如：一根手指停下重拳）。
3. **视觉奇观型**：通过不可思议的画面制造爽感（如：废柴的血滴在废铁上，废铁瞬间重组为流光溢彩的神器）。

### 三、 反派层级与“仇恨值”设计
没有好反派，就没有强爽感。反派的存在就是为了被视觉化打脸。
- **小反派 (炮灰)**：存在 1-5 集。行为：狗眼看人低、当众嘴碎。结局：被主角的财力或一巴掌直接拍飞。
- **中反派 (精英)**：存在 5-25 集。行为：利用规则或资本陷害主角。结局：底牌被主角全部撕碎，身败名裂。
- **大反派 (终极)**：贯穿全剧。行为：主角一切痛苦的根源。结局：在最高规格的特效和精细画面中被轰杀至渣。

## 节奏设计与三幕微结构

### 核心理念

短剧节奏的本质是**情绪管理**。编剧不是在写故事，而是在设计观众的情绪过山车。每一秒都在回答一个问题："观众现在的情绪是什么？接下来要把它推向哪里？"

节奏把控的铁律：**永远不给观众退出的机会。**

### 单集三幕微结构

每集2-3分钟，内部遵循紧凑的三幕结构：

```
┌─────────────────────────────────────────────────────┐
│  第一幕：钩子引爆（前30秒）                            │
│  ├─ 承接上集悬念（回应上集钩子）                        │
│  ├─ 5秒内建立本集核心冲突                              │
│  └─ 观众情绪：好奇/紧张/愤怒                           │
│                                                       │
│  第二幕：冲突升级（中间1-1.5分钟）                      │
│  ├─ 冲突层层叠加，至少1个反转                          │
│  ├─ 角色碰撞推动剧情，台词密集有力                      │
│  ├─ 新信息不断注入，保持观众好奇                        │
│  └─ 观众情绪：焦虑/期待/心疼/愤怒升级                   │
│                                                       │
│  第三幕：爽点释放 + 钩子（最后30-45秒）                 │
│  ├─ 本集的核心爽点或情绪顶峰                           │
│  ├─ 最后10秒：下集悬念钩子                             │
│  └─ 观众情绪：爽快/震惊 → 立刻想看下一集               │
└─────────────────────────────────────────────────────┘
```

#### 四大阶段节奏分配（占比为参考区间，集数随总集数缩放）

> 下表以"约60集爽剧"为参照。实际市场40/70/80/120集并存——**按总集数等比缩放，不要硬套60集**。
> 不同题材曲线不同：甜宠"快引爆→长拉扯→快大婚"；长烧悬疑"慢积累→反转爆发→极快收"。

| 阶段 | 占比参考 | 节奏特征 | 核心任务 |
|------|---------|---------|---------|
| 开局引爆(含一卡) | ~20% | 极快，密集冲突 | 建人设、核心矛盾、一卡卡点(见 一卡设计（前10集 / 投稿单元 / 付费卡点 / 审核节点）) |
| 升级发展 | ~30% | 快，持续升温 | 扩大冲突、引入新角色新势力 |
| 高潮连击 | ~33% | 最快，高密度反转 | 多线交汇、真相揭露、大逆袭 |
| 终局收束 | ~17% | 先极快后收束 | 终极对决、情感升华、大结局 |

#### 关键节点设计（位置用"全剧占比"表达，按总集数换算）

| 位置 | 节点类型 | 内容要求 |
|------|---------|---------|
| 第1集 | 爆炸开场 | 前1-2分钟内引爆核心矛盾，建立主角困境 |
| ~5% 处 | 初始爽点/金手指 | 主角第一次小胜利/身份微露/转折点出现 |
| **一卡卡点(约第10集/付费分界)** | 💰 超大卡点 | 全剧第一个超大卡点(断亲/离婚/身份揭露)，戛然而止 |
| ~25% 处 | 第一转折点 | 主角处境根本变化 |
| ~35% 处 | 新势力登场 | 引入更强对手/更复杂局面(长篇续航靠反派轮换，非反派一味变强) |
| ~50% 处 | 中点大反转 | 故事走向重大转折 |
| ~2/3 处 | 至暗时刻 | 主角遭遇最大危机 |
| ~75% 处 | 终极反击启动 | 绝地反击，进入终局 |
| 末段 | 高潮连爆 → 大结局 | 多线汇聚连爆 + 情感收束 + 圆满/开放结局 |

> 长篇(80集+)防后劲不足：开支线加强关联新人物、提前埋多钩子逐个拆解、反派轮换。详见 情绪升级（六层拉扯 / 后悔流双曲线 / 延迟满足 / 禁止翻旧账） "故事点换续航"。

### 节奏控制技巧

#### 加速节奏的方法

- **跳切叙事**：省略过渡，直接跳到下一个冲突点
- **台词对抗**：用角色间你来我往的犀利对话推进
- **多梗叠加**：一个场景内连续放出多个信息/反转
- **短句密集**：台词和描写都用短句，制造紧迫感
- **时间压力**：设置倒计时或截止日期增加紧张感

#### 减速节奏的方法（爽剧少用；甜宠/后悔流的情感拉扯段可适当多用）

- **暴风雨前的宁静**：大冲突前短暂的温馨场景，反衬即将到来的风暴
- **情感铺垫**：为虐心或感动场景做情绪蓄力
- **信息消化**：重大真相揭露后给观众1-2分钟消化

减速的铁律：**不超过半集**。一旦超过，立刻用反转或新冲突重新点燃。

#### 反转设计要点

| 反转层级 | 频率 | 效果 |
|----------|------|------|
| 微反转 | 每集2-3个 | 小惊喜，保持注意力 |
| 中反转 | 每3-5集1个 | 剧情走向调整，新信息揭示 |
| 大反转 | 每10-15集1个 | 颠覆认知，格局变化 |
| 终极反转 | 全剧1-2个 | 核心真相揭露，故事彻底改变 |

### 上下集衔接法则

#### 无缝衔接原则

上一集的最后一个画面/台词，必须与下一集的第一个画面/台词形成连贯。

| 衔接方式 | 示例 |
|----------|------|
| 台词延续 | 上集结尾："你以为你赢了？" → 下集开头："可惜——"（主角转身） |
| 动作延续 | 上集结尾：一巴掌挥出 → 下集开头：巴掌被一只手稳稳接住 |
| 悬念回应 | 上集结尾：门被推开 → 下集开头：门后站着一个所有人没想到的人 |
| 场景跳转 | 上集结尾：A场景的悬念 → 下集开头：B场景的新冲突，A悬念在中段回应 |

#### 衔接禁忌

- ❌ 下一集开头完全重复上一集结尾内容（浪费时间）
- ❌ 上一集的钩子在下一集被轻描淡写带过（破坏信任）
- ❌ 下一集开头用大段旁白回顾剧情（拖节奏）
