# 艾玛短剧 · 中文对白诊断

把对白视为人物施加影响的言语行动。识别同一信息、态度、策略和力度原地循环的车轱辘话，同时保护有策略升级、情绪结算、观众代偿、权力压迫、喜剧节奏、表演峰值或意义反转的必要重复与直白表达。

## 路由与授权

- 用户问概念或判断标准：解释并给可执行判据。
- 用户要求审查、诊断或逐句分析：只诊断，不提供完整替换稿。
- 用户要求精简、提纯、重写或优化：诊断后完成指定对白改写。
- 用户要求整场动作、场景节奏和人物表现的综合精修：使用 `em-script-refine`。
- 用户要改变事件、动机、关系、秘密、线索或结局：使用 `em-adaptation`。
- 用户要中英转换或已有英文对白打磨：分别使用 `em-us-localization` 或 `em-english-polish`。

近邻任务可以提示对应模块，但不要把对白请求扩大成整剧改造。改剧本项目文件前使用 `drama-truesource` 核对 `_真源指针.md` 与锁定项；只分析用户贴出的片段时不创建或更新真源。

## 核心判据

每次诊断或精修先用三个问题判断取舍：**特定性**（此人为何此刻对这个对象说）、**目的性**（希望对方听完怎样回应）、**必要性**（删掉会损失什么信息、关系变化或情绪体验）。课程操作方法与案例见 [0930台词打磨](references/course-0930.md)；涉及做减法、信息负载、职业与口头禅、称呼、内心／画外音或用户点名0930课程时读取相关部分。

提高负载时先看动作已表达什么，让一句话自然兼顾任务、关系或代价；不把全部背景挤进对白。课程建议尝试缩短三分之一是诊断实验，不是删减指标。人物的认知与情绪须有已知事实支撑；缺观察、记忆或前情时指出缺口，只改台词不暗增场景事实。

车轱辘话不是字面重复，而是：

`同一信息或态度 + 同一策略 + 同一力度 + 没有新的叙事、情绪、关系或表演后果 = 戏剧状态停滞`

分别判断三种贡献：

- **叙事效率**：新信息、新筹码、新策略、新决定或新后果。
- **情绪效率**：蓄压、释放、宣判、站队、观众代偿或关系结算。
- **表演效率**：爆发、停顿、反转、崩溃、低温决裂或类型卡点。

不要求每句同时满足三轨。直白、绝对、喊满、狗血或缺少潜台词都不自动等于坏台词；先判断类型契约、前文蓄压、所在节点及后续反应。

对明情绪台词区分：

- **有效爆发**：首次完成公开反抗、情绪结算、阵营切割或期待兑现，并改变关系或行动。
- **纯宣泄**：没有新信息，但承担唯一峰值、观众嘴替或演员爆点；可保留核心句，优先检查后续是否需要关系宣判或行动落地。
- **无效空喊**：没有铺垫、不是新情绪阶段、对方可原样回应且没有后果；删除、合并或移到真正峰值。

需要理论来源、六轴边界、正反例或争议性重复的详细校准时，完整读取 [dialogue-framework.md](references/dialogue-framework.md)。

## 诊断与改写

1. **锁定场景契约。** 概括谁为了什么对谁采取语言行动、对方怎样抵抗、冲突最终改变什么；列出必须保留的事实、动作、知识、关系、情绪节点与结尾后果。
2. **标出台词功能。** 逐句判断表层信息、真实意图、策略、叙事／情绪／表演功能、对方反应和状态变化。任务较短时不必展示完整账本。
3. **归组重复链。** 查找同功能、同力度的请求、拒绝、指责、辱骂、威胁或背景复述。指出它为何停滞，不因出现相同词就判重复。
4. **保护有效复沓。** 目的相同但策略、压力、表演状态、意义或关系对象发生变化时保留；说明可观察的新作用，不能只说“更有情绪”。
5. **重建攻防。** 改写时让每轮回应上一轮并制造下一轮麻烦，可通过新筹码、反制、被迫选择或具体代价推进。背景信息作为冲突资源进入，不让人物暂停争斗念履历。
6. **检查人物与口语。** 长短句、打断、回避、称谓和力度符合人物及类型；强句来自具体关系和后果，不写成可移植金句。

## 不变量

- 保留既定事件、动作顺序、人物知识、关系状态、动机、道具、线索、秘密、情绪转折和结尾钩子。
- 不为更强台词虚构伤害、证据、往事、身份或决定。
- 不把所有人物改成同一种简短、聪明或会说金句的声音。
- 不强迫每句都有潜台词，也不把所有高强度表达降成克制、冷感或文学化。
- 不因追求简洁删除使背叛、拒绝、打击、动手或威胁成立的情绪台阶。
- 未获改写授权时不回写文件或附完整替换稿；已获授权时直接完成范围内改写，不逐句重复确认。

## 验证与输出

依据成品核验：没有新增事实；相邻轮次不在同一信息、策略和力度上打转；关键情绪由铺垫、爆发与反应支撑；人物声音可区分；动作与对白不重复解释；目标类型的明示和夸张尺度得到保留；用户请求范围全部覆盖。

输出随请求调整，但必须可观察：

- 概念解释给出定义、非机械判据、正反例和检查问题。
- 只诊断标出场景契约、重复链、有效复沓、停滞证据与优先建议，不附完整改写。
- 诊断并改写提供保持原格式的新版对白，并说明删除或合并了什么、保留了哪些信息和功能、是否存在需要用户决定的事实。

以下情况只暂停受影响部分：原文缺失导致无法逐句判断；改写依赖会改变关系、事实、锁定项或结局的未知选择；权威底稿冲突无法裁决。只要求判断且诊断已完成，或继续压缩会损害必要情绪与表演过程时结束，不为固定改动数、固定轮数或主观高分继续重写。

## 情绪括注：必要、准确、可表演（用户要求，2026-09-15）

用户要求参考对标对白的情绪表现，但明确修正“全都加”为“把必要的感情都用括号加上”。在哭腔、惊惧、强压怒火、讥讽、哀求、装痛、突然转冷等会改变一句话读法的位置，使用 `人物（表演提示）：台词`；平直交代和已由紧邻动作充分表达的情绪可不加。

括号给一个主要、可表演的方向，必要时保留转折或电话／VO标记；长动作仍写动作行。不把每个角色都标成大哭或暴怒，不堆相互矛盾的形容词，也不为新增括注拆开同人完整发言。参考台词可在用户授权范围改写其攻防和力度，必须符合当前人物关系与事件，不能只换名字就搬入不存在的往事、伤害或身份。

## 成文格式：同一角色连续发言

交付完整场次时，除非用户另定格式，每场标题后的首条非空内容单列 `人物：……`，核对实际出镜、发声与功能角色。仅交对白替换表时不为补名单虚构场次或动作。

- 同一角色连续说话，中间没有他人回应、动作、字幕、音效、转场或场次切换时，默认合为一段完整发言，只写一次人物名。连续三句以上也须整链合并；空行、分页、换语气标签不是新的发言回合。
- 括号保留一个主导的语气／表演提示。“耳语、诱导、气息急促、侵略感”等同一轮中的提示应归纳，不逐句重复角色名。包含真实动作或关键情绪转折的信息不能丢，可在原位置保留简短段内提示；独立动作及真正中断发言的节拍仍保留分段。
- “合成一句”指一次发言一个对白段落；段内可以有问号、句号和自然停顿，不强行用逗号串成病句。不因合并删事实、改顺序或削弱威胁、反抗等原有意图。
- 内心、画外音与当面对白按项目规范明确区分；未另有合并约定时，发声方式切换保留分段，不能把心声变成对方听见的话。中英对照须保留逐段对应；只获准改英文时不据此改动中文或动作。
- 交付前单独扫描全部同角色相邻对白链，包含不同语气提示的链；修正可合并项后复扫。只诊断时指出问题，已授权成文或改稿时落实合并。不可为凑零残留跨越真实动作或声音边界。

例如 `林舟（低声）：钥匙给我。／林舟（威胁）：别逼我动手。` 应成文为 `林舟（低声威胁）：钥匙给我。别逼我动手。`；若两句中间有人拦住他，保留该动作及前后台词的分段。
